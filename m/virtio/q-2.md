## 记录 dummy-virtio 的测试

如果使用 arg_virtio_dummy="-device virtio-dummy "
```txt
qemu-system-x86_64: -device virtio-dummy: No 'virtio-bus' bus found for device 'virtio-dummy'
如果使用 arg_virtio_dummy="-device virtio-dummy-pci "
```txt
qemu-system-x86_64: -device virtio-dummy-pci: device is modern-only, use disable-legacy=on
```

原来 qemu 的 -device 功能如此之强啊，可以选择 -device virtio-dummy 也可以 -device virtio-dummy-pci
但是诡异之处在于居然可以歪打正着，而且还是可以用的

如果把 hw/virtio/virtio-balloon-pci.c 直接给删掉，那么 qemu 还是可以正常工作的，只有会有这个问题:
```txt
qemu-system-x86_64: -device virtio-balloon: 'virtio-balloon' (alias 'virtio-balloon-pci') is not a valid device model name
```
