# 饥荒开局：采集 → 科技 → 装备

目标：在探索中做出 **猪皮头盔、火腿棒、提灯**，分别解决防御、输出和照明；背包负责携带资源。将原片叙述重组为操作路线，数值沿用原片，未核验当前游戏版本。

原片：[饥荒萌新终极入门攻略！](https://www.bilibili.com/video/BV1n8411d7SL/)，亚丹Ardent，约9分16秒。

## 1. 路线与材料速查

**出生地采草、树枝、燧石和食物 → 混合矿区采木头、石头、金子 → 科学机器 → 背包、木甲、铲子（长矛可选） → 打包炼金引擎 → 取得猪皮、大肉、荧光果 → 在方便回访的位置放下引擎 → 三件核心装备。**

| 阶段 | 做什么 | 达成条件 / 限制 |
| --- | --- | --- |
| 采集 | 草、树枝最好各备一组；捡燧石、浆果、萝卜 | 工具材料与食物并行 |
| 一级科技 | 科学机器；背包、木甲、铲子 | 在机器旁解锁；背包与木甲冲突 |
| 二级科技 | 加工材料，制作炼金引擎后取消放置 | 原料已扣，建筑未落地；尚不能提供科技 |
| 探索 | 猪人房 / 试金石、浣猫 / 高脚鸟、洞口 | 分别取猪皮、大肉、荧光果 |
| 装备 | 头盔 + 火腿棒 + 提灯 | 防具要穿，武器会腐坏，灯要有燃料 |

| 物品 | 配方 | 科技 / 用途 |
| --- | --- | --- |
| 科学机器 | 4木头 + 4石头 + 1金子 | 一级科技 |
| 背包 | 4草 + 4树枝 | 一级；身体栏；增加8格 |
| 木甲 | 8木头 + 2绳子（6草） | 一级；身体栏；原片记80%减伤、325耐久 |
| 铲子 | 2树枝 + 2燧石 | 一级；挖树桩与植物 |
| 炼金引擎 | 4木板 + 2石砖 + 2电子元件 | 一级制作，提供二级科技；折合16木头 + 12石头 + 4金子 |
| 猪皮头盔（橄榄球头盔） | 1猪皮 + 1绳子（3草） | 二级；头部栏；可与背包同时装备 |
| 火腿棒 | 1猪皮 + 2树枝 + 2大肉 | 二级；新鲜时约59.5伤害，会腐坏 |
| 提灯 | 2荧光果 + 3树枝 + 2绳子（6草） | 二级；可补燃料，可放地上照明 |

**材料口径：** 引擎折算只算引擎本身，不含科学机器和其他装备。三件核心装备合计 **2猪皮、2大肉、2荧光果、5树枝、3绳子（9草）**，还要另备工具、食物与燃料。这是按配方汇总的规划补充。

## 2. 找矿区，建立一级科技

**出生地先补基础资源。** 原片将出生地简化为森林、绿地、草原三种地貌；草、树枝、燧石是工具起点，浆果与萝卜用于充饥。草与树枝最好各备一组。 [采集画面](../../../../vn-resources/bilibili/BV1n8411d7SL/frames/012.jpg) · [采集与探图 00:32–01:40](../../../../vn-resources/bilibili/BV1n8411d7SL/BV1n8411d7SL.mp4#t=32,100)

**围绕出生地找混合矿区。** 看树林与矿石的资源组合，别只认地面颜色。原片列出陨石区、宠物巢穴区、矿区、混合区、坟区五类组成；树、石头、金矿相邻，适合一次收齐科技材料。作者简化了它与出生地的连接关系，这里作为找图线索。 [地图关系](../../../../vn-resources/bilibili/BV1n8411d7SL/frames/014.jpg) · [混合地貌](../../../../vn-resources/bilibili/BV1n8411d7SL/frames/018.jpg)

**斧头砍树、镐子采石头和金子 → 科学机器 → 在机器旁解锁原型。** 优先背包、木甲、铲子：分别补携带能力、战斗防护与采集效率。长矛是可选过渡武器，原片记约34攻击，比斧头高约7，提升有限。 [科学机器配方](../../../../vn-resources/bilibili/BV1n8411d7SL/frames/025.jpg) · [解锁演示 01:57–02:33](../../../../vn-resources/bilibili/BV1n8411d7SL/BV1n8411d7SL.mp4#t=117,153)

**高脚鸟先绕开。** 大眼睛、长腿、地面鸟巢；靠近鸟或巢、偷蛋会招来攻击与追击。裸装时先完成采集，装备齐后再考虑用它取大肉。 [鸟与巢](../../../../vn-resources/bilibili/BV1n8411d7SL/frames/021.jpg) · [追击演示 01:40–01:57](../../../../vn-resources/bilibili/BV1n8411d7SL/BV1n8411d7SL.mp4#t=100,117)

## 3. 装备栏与采集：容易误解的机制

**背包和木甲占同一个身体栏。** 背包增加8格；木甲只有穿上才减伤，放物品栏无效。背包探图 → 遇敌才切木甲，容易来不及；计划战斗前检查装备栏和耐久。后续猪皮头盔解决这项冲突：头部防护，身体背包。 [木甲配方](../../../../vn-resources/bilibili/BV1n8411d7SL/frames/032.jpg) · [切换与遇袭 02:33–03:05](../../../../vn-resources/bilibili/BV1n8411d7SL/BV1n8411d7SL.mp4#t=153,185)

**砍完树再用铲子挖树桩，补一份木头。** 铲子还可挖起草、树枝用于移植，原片展示挖蘑菇、红木根。前期不建议挖坟：精神值损失会增加后续麻烦。 [挖树桩](../../../../vn-resources/bilibili/BV1n8411d7SL/frames/039.jpg) · [铲子用途 03:05–03:21](../../../../vn-resources/bilibili/BV1n8411d7SL/BV1n8411d7SL.mp4#t=185,201)

## 4. 炼金引擎：先制作，后选址

**16木头、12石头、4金子 → 在科学机器旁加工4木板、2石砖、2电子元件 → 制作炼金引擎。** 后面还要探索不同资源，放太偏会多跑回头路，甚至再造一座。 [材料画面](../../../../vn-resources/bilibili/BV1n8411d7SL/frames/045.jpg) · [材料说明 03:27–03:48](../../../../vn-resources/bilibili/BV1n8411d7SL/BV1n8411d7SL.mp4#t=207,228)

**打包：点击制作 → 绿色放置预览 → 取消放置 → 到合适地点从同一配方再次进入放置。** 材料已消耗，建筑未在地图上落地；没有实体包裹可捡，也尚未提供二级科技。 [待放置预览](../../../../vn-resources/bilibili/BV1n8411d7SL/frames/047.jpg) · [完整操作 03:48–04:23](../../../../vn-resources/bilibili/BV1n8411d7SL/BV1n8411d7SL.mp4#t=228,263)

离开矿区前作者建议再备至少一组金子。收齐猪皮、大肉、荧光果后，在易回访的位置放引擎；也可先选交通便利地点落地，再收材料。靠近引擎解锁三件核心装备。 [选址说明 08:23–08:44](../../../../vn-resources/bilibili/BV1n8411d7SL/BV1n8411d7SL.mp4#t=503,524)

## 5. 猪皮与大肉：按现有条件选路线

| 缺什么 | 去哪里 / 怎么做 | 原片记录的收益 | 条件与代价 |
| --- | --- | --- | --- |
| 猪皮 | 桦树林、常青树密集森林；锤拆猪人房 | 每房2猪皮、2石砖、2木板 | 推荐新手；拆房不会像打猪那样引发攻击仇恨 |
| 猪皮 | 偶遇试金石，锤周围4个猪头 | 共8猪皮 | 顺路利用，无需专门绕图寻找 |
| 大肉 | 桦树林打浣猫 | 每只1大肉 | 原片演示它常来不及还手，仍应准备防具 |
| 大肉 | 矿区打高脚鸟 | 每只2大肉 | 木甲 + 长矛；打两下再躲避 |
| 猪皮 + 大肉 | 同一猪人喂满4怪物肉 → 疯猪 → 击败 | 1猪皮 + 2大肉 | 疯猪主动攻击；原片用打两下再躲避 |

**拆房顺便补科技材料。** 未提前打包引擎时，掉落木板、石砖也能用于制作。普通猪人不是优先猪皮来源：原片记约250血、33攻击、会走位，附近猪人可能联动仇恨，猪皮掉率约33%。 [拆房掉落](../../../../vn-resources/bilibili/BV1n8411d7SL/frames/063.jpg) · [拆房与寻找 04:45–05:22](../../../../vn-resources/bilibili/BV1n8411d7SL/BV1n8411d7SL.mp4#t=285,322) · [试金石猪头](../../../../vn-resources/bilibili/BV1n8411d7SL/frames/066.jpg)

**高脚鸟先穿木甲。** 用长矛打两下后躲避；原片也演示不会走位时准备两副木甲硬打，会消耗防具与血量。浣猫是探索中的另一条路线，每只1大肉。 [高脚鸟动作 06:25–06:38](../../../../vn-resources/bilibili/BV1n8411d7SL/BV1n8411d7SL.mp4#t=385,398) · [浣猫 06:38–06:43](../../../../vn-resources/bilibili/BV1n8411d7SL/BV1n8411d7SL.mp4#t=398,403)

**喂1块和4块怪物肉是两种用途。** 1块可暂时雇佣猪人帮忙砍树、打架；同一猪人满4块变疯猪，主动攻击，不会像普通猪人那样走位；原片称不与普通猪人联动仇恨。先准备护甲与武器再触发。 [雇佣与转化 06:43–07:00](../../../../vn-resources/bilibili/BV1n8411d7SL/BV1n8411d7SL.mp4#t=403,420) · [疯猪打法 07:00–07:13](../../../../vn-resources/bilibili/BV1n8411d7SL/BV1n8411d7SL.mp4#t=420,433)

## 6. 三件核心装备：用途与失效条件

**猪皮头盔：1猪皮 + 1绳子，二级解锁。** 原片称防御属性与木甲相同；关键优势是占头部栏，可与背包共存。制作后要装备，留意耐久。 [头盔配方](../../../../vn-resources/bilibili/BV1n8411d7SL/frames/068.jpg) · [装备说明 05:26–05:47](../../../../vn-resources/bilibili/BV1n8411d7SL/BV1n8411d7SL.mp4#t=326,347)

**火腿棒：1猪皮 + 2树枝 + 2大肉，二级解锁。** 新鲜伤害约59.5，原片两下击杀普通蜘蛛；挥击不按次数耗耐久，但约6天腐坏，伤害逐渐降到约29.5。“无限耐久”不能理解为永久使用；第一批大肉先考虑留2块做武器。 [火腿棒配方](../../../../vn-resources/bilibili/BV1n8411d7SL/frames/074.jpg) · [伤害与腐坏 06:00–06:23](../../../../vn-resources/bilibili/BV1n8411d7SL/BV1n8411d7SL.mp4#t=360,383)

**荧光果：镐子挖开洞口石堆 → 下洞 → 入口附近采发光植物 → 回地面。** 原片简化了入口相连地形，目的是就近取果，不是深入洞穴。整理补充：第一次下洞先备临时照明，记住返回入口，别等提灯做完才考虑光源。 [洞口](../../../../vn-resources/bilibili/BV1n8411d7SL/frames/089.jpg) · [荧光果植物](../../../../vn-resources/bilibili/BV1n8411d7SL/frames/091.jpg) · [下洞采集 07:13–07:40](../../../../vn-resources/bilibili/BV1n8411d7SL/BV1n8411d7SL.mp4#t=433,460)

**提灯：2荧光果 + 3树枝 + 2绳子，二级解锁。** 比火把光圈大、持续久；原片加速演示没有给精确持续时间。荧光果每个补约19%燃料。用斧头等手持工具时，把点亮的灯放地上，在光圈内工作；走出光圈前取回。 [提灯配方](../../../../vn-resources/bilibili/BV1n8411d7SL/frames/093.jpg) · [补燃料与放地上 08:08–08:23](../../../../vn-resources/bilibili/BV1n8411d7SL/BV1n8411d7SL.mp4#t=488,503)

**最后检查：** 头盔正在穿、耐久足；火腿棒新鲜；提灯有燃料；有食物与返程路线。开局装备不能替代怪物招式知识，结尾挑战强敌后死亡说明了路线边界。 [结尾 08:44–09:15](../../../../vn-resources/bilibili/BV1n8411d7SL/BV1n8411d7SL.mp4#t=524,555.19)
