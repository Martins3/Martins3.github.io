## P01 开荒发育篇

[P01 开荒发育 · 完整原片](../../../../vn-resources/bilibili/BV1n8411d7SL/p01/video.mp4#t=0,555) · [在 B 站观看开荒发育篇](https://www.bilibili.com/video/BV1n8411d7SL/)

本集目标是做出 **猪皮头盔、火腿棒、提灯**，分别解决防御、输出和照明；背包负责携带资源。

### 1. 路线与材料速查

**出生地采草、树枝、燧石和食物 → 混合矿区采木头、石头、金子 → 科学机器 → 背包、木甲、铲子（长矛可选） → 打包炼金引擎 → 取得猪皮、大肉、荧光果 → 在方便回访的位置放下引擎 → 三件核心装备。**

| 阶段 | 做什么 | 达成条件 / 限制 |
| --- | --- | --- |
| 采集 | 草、树枝最好各备一组；捡燧石、浆果、萝卜 | 工具材料与食物并行 |
| 一级科技 | 科学机器；背包、木甲、铲子 | 在机器旁解锁；背包与木甲冲突 |
| 二级科技 | 加工材料，制作炼金引擎后取消放置 | 原料已扣，建筑未落地；尚不能提供科技 |
| 探索 | 猪人房 / 试金石、浣猫 / 高脚鸟、洞口 | 分别取猪皮、大肉、荧光果 |
| 装备 | 头盔 + 火腿棒 + 提灯 | 防具要穿，武器会腐坏，灯要有燃料 |

| 物品 | 配方 | 科技 / 用途 |
| --- | --- | --- |
| 科学机器 | 4木头 + 4石头 + 1金子 | 一级科技 |
| 背包 | 4草 + 4树枝 | 一级；身体栏；增加8格 |
| 木甲 | 8木头 + 2绳子（6草） | 一级；身体栏；原片记80%减伤、325耐久 |
| 铲子 | 2树枝 + 2燧石 | 一级；挖树桩与植物 |
| 炼金引擎 | 4木板 + 2石砖 + 2电子元件 | 一级制作，提供二级科技；折合16木头 + 12石头 + 4金子 |
| 猪皮头盔（橄榄球头盔） | 1猪皮 + 1绳子（3草） | 二级；头部栏；可与背包同时装备 |
| 火腿棒 | 1猪皮 + 2树枝 + 2大肉 | 二级；新鲜时约59.5伤害，会腐坏 |
| 提灯 | 2荧光果 + 3树枝 + 2绳子（6草） | 二级；可补燃料，可放地上照明 |

**材料口径：** 引擎折算只算引擎本身，不含科学机器和其他装备。三件核心装备合计 **2猪皮、2大肉、2荧光果、5树枝、3绳子（9草）**，还要另备工具、食物与燃料。这是按配方汇总的规划补充。

## P02 冬季生存篇

[P02 冬季生存 · 完整原片](../../../../vn-resources/bilibili/BV1Xr421W7uA/p02/video.mp4#t=0,530) · [在 B 站观看冬季生存篇](https://www.bilibili.com/video/BV1Xr421W7uA/)

### 保暖：先加热，再规划下一次补热

体温降到零以下会持续掉血。基地用石头火坑取暖；离开火源后体温又会下降，保暖衣物只是减缓降温，不会自己产热。原片优先推荐暖石：**10 石头、3 燧石、1 把镐子**，旧镐也能用于制作。靠近火源加热，颜色越红表示储热越多，再带着出门；不能只看背包里“有暖石”就认为能过冬。

野外补热可以点燃一棵孤立的树，把暖石放在靠近燃烧树的位置加热，再取回。不要靠着基地、密集树林或掉落物放火。原片演示一次烧树补热可支持一段探索，但续航随环境与加热程度变化，路线仍要留返程余量。温差变化过大时暖石会掉耐久，耐久不足可用缝纫包修理。[P02 00:20–01:38 体温、暖石与野外补热](../../../../vn-resources/bilibili/BV1Xr421W7uA/p02/video.mp4#t=20,98)

### 植物停产：减少草和树枝的消耗

冬季多数基础植物停止再生，之前随手用火把的习惯会让草、树枝越来越少。外出改用提灯或矿工帽，以荧光果补燃料；基地用石头火坑兼顾照明和取暖。常青树仍能生长，砍成熟树后把种子补种，建立持续木材来源。

砍树可能唤醒树精。原片给出两种处理：会走位时打四走一；暂时打不过就种树尝试安抚，不把树精拖进基地。冬季砍树不是只捡木头，还要留意树精和补种。[P02 01:38–02:50 冬季资源与树精](../../../../vn-resources/bilibili/BV1Xr421W7uA/p02/video.mp4#t=98,170)

### 冬季食物：把冰变成填充物

兔子、猪、牛和蜘蛛仍可提供肉；蜘蛛巢尤其适合持续获取怪物肉。靠近海岸可能触发企鹅登陆，企鹅据点附近生成冰矿；挖冰而不是主动挑战成群企鹅。原片演示用冰替代浆果等填充物做肉丸。

**一块大肉或怪物肉加三块冰**可走肉丸路线；原片特别提醒，**一块小肉加三块冰会优先得到兔子炖菜**，想用小肉做肉丸可改为两块小肉加两块冰。不能把不同肉类与菜谱优先级都当成一样。怪物肉控制在一块，避免怪物千层饼。冬天的冰便于积存，入春会融化；用齿轮做冰箱，把冰放进去以长期保存。[P02 02:50–04:20 取肉、挖冰与烹饪区别](../../../../vn-resources/bilibili/BV1Xr421W7uA/p02/video.mp4#t=170,260)

### 海象：先追到回巢，再输出

牛在发情时会主动攻击，戴牛角帽或绕行；猎犬波次也会增强，冰猎犬死亡产生的冻结效果可以影响周围敌人，别只盯着单只狗。

海象营地的组合是远程海象父亲、海象儿子和猎犬。原片方法不是站着吃吹箭：**沿直线持续追父亲 → 拉到离营地足够远 → 等它进入慢慢回巢的行为 → 趁它不再逃跑时击杀**。紧贴追赶与远距离受箭不同，追逐路线不要绕障碍拖慢自己。掉落吹箭可用于处理逃跑的小海象；海象牙做手杖，提供移速；贝雷帽适合日常回精神。掉落有概率，不能把第一次没有牙当成操作失败。[P02 04:20–06:20 海象追逐与战利品](../../../../vn-resources/bilibili/BV1Xr421W7uA/p02/video.mp4#t=260,380)

### 巨鹿：先保护基地，再选择打法

原片按默认世界第一年约第 30 天夜晚讲解巨鹿。听见吼声或人物提示后先离开基地，不要在锅、冰箱和箱子旁等它。巨鹿对建筑的索敌范围比对玩家远，可在远离基地的战场放指示牌引它过来；只是甩在野外能暂时保住家，却会错过眼球这一春季防雨材料。

已有树精时可引巨鹿踩树，触发双方交战；不要把“地图上有树精”当成必然能借力，需实际引到同一位置。自己硬打的原片配置是三件木甲、新鲜火腿棒与四个饺子。战场木头火堆利用燃烧特性帮助抵御冻结，但要远离易燃建筑、树木。攻击时站在可攻击距离的边缘，减少贴得过近造成的精神下降。

走位法观察冰锥方向，在攻击前横向绕开，再返回输出；原片以打五走一示范。次数受移速、延迟和进入时机影响，练习时先保证躲开，不能看到“第五下”才临时反应。[P02 06:20–08:40 巨鹿引导、站打与横向走位](../../../../vn-resources/bilibili/BV1Xr421W7uA/p02/video.mp4#t=380,520)

### 潮湿的连锁问题与防雨叠加

雨水提高潮湿度，进而降温、掉精神；物品湿滑还可能在使用时脱手。只想着“精神低就打影怪”无法解决武器脱手的问题，首先要防雨。

| --- | --- | --- |
| 树荫 | 30% | 要留在树下 |
| 草帽 | 20% | 不能单独抵挡持续下雨 |

### 发情、青蛙雨与借力

春季牛群发情，普通蜜蜂也更具攻击性；不要按秋天的安全距离穿过它们。青蛙雨会在玩家附近不断产生青蛙，攻击还会打掉物品；主动还手容易吸引成群围攻，清掉一批也不能终止降雨。

原片的借力路线是去牛群附近，让牛与青蛙互相攻击，结束后再收集蛙腿、大肉。前提是自己有安全走位、牛帽或足够距离；不能跑进双方中间，也不要把牛群耗到灭绝。剩余肉类可通过鸟笼转蛋，再找猪王换金子。它是转移风险的方法，不是直接站在牛群里免疫伤害。[P03 03:50–05:48 春季生物与青蛙雨](../../../../vn-resources/bilibili/BV12oJu69Eto/p03/video.mp4#t=230,348)

### 植物收益与食人花

雨水有利于花、蘑菇和农作物生长；但玩家活动区也可能长食人花。眼球草在可生长的地皮上围着本体出现，会攻击并收走地面物品。铺木地板可避免基地里长出眼球草；清理时先打出通往本体的安全路线，再处理不会主动还击的本体，取回尚未消化的物品及种子。

把食人花移到船上，原片演示只产叶肉、不长眼球草的用法。叶肉不是普通蔬菜：一叶肉加三蔬菜可做牛肉绿叶菜，二叶肉加二蜂蜜可做叶肉蜜，分别偏向补血、饱食与大量回精神。[P03 05:48–07:00 春季植物、食人花与叶肉](../../../../vn-resources/bilibili/BV12oJu69Eto/p03/video.mp4#t=348,420)

### 麋鹿鹅：攻击机会取决于护崽状态

树枝围成的巢可能出现大鹅并孵出五只小鹅。小鹅会吃周围食物，因此不要在巢旁建食品生产区。战利品鹅毛可用于风向标与羽毛扇。

大鹅会吼掉手持武器，硬打要预备足够护甲、回复品并及时捡回武器；原片举火腿棒、约四件木甲及五个饺子的配置。走位示范是打三走一，但护崽时拉开距离可能使大鹅放弃追击、返回小鹅，打乱循环。优先选刚下蛋、尚未进入护崽纠缠的时机。大鹅死亡后小鹅进入复仇状态，旋转冲刺一段时间后会眩晕，趁停下输出，再退出下一轮冲刺。杀掉母亲后并非战斗结束，毛的主要来源反而是小鹅。[P03 07:00–09:08 鹅巢、大鹅与小鹅反击](../../../../vn-resources/bilibili/BV12oJu69Eto/p03/video.mp4#t=420,548)

## P04 开局回复篇

### 饥饿、精神、生命分别解决

饱食度归零会掉血，精神低会引来影怪，生命耗尽才直接死亡。开局先用能就地获取的资源维持三维，不必为恢复先完成航海、月岛等复杂任务。

胡萝卜可先采先吃，烤熟增加回血，但采一根少一根，原片说明再生较慢，不能当作唯一长期食源。普通浆果生吃约 9 饱食，熟吃约 12.5；野生浆果丛数天后再生。多汁浆果一次采三颗，产量与保质期都不同，成熟后再摘、摘后及时用，别为了囤积一次采遍地图而放烂。[P04 01:04–02:22 胡萝卜、浆果与移植](../../../../vn-resources/bilibili/BV1Fy4y1F79r/p04/video.mp4#t=64,142)

移植浆果丛后要施肥，腐烂食物和粪便都可使用；后续多次收获仍需再次施肥。判断是否枯萎比只计算过去几天更直接。

### 回精神：花、仙人掌与蘑菇有区别

摘普通花直接回 5 精神；恶魔花采摘和靠近都有负面效果。不要把所有“花”都当回复资源。沙漠仙人掌采摘会伤血，先穿护甲再采；烤熟可回 15 精神，生吃反而损失血量和精神。

| 蘑菇 | 采集时间 | 原片用途与风险 |
| --- | --- | --- |
| 红蘑菇 | 白天 | 生吃损血，熟吃损精神；不作为萌新直接回复食物 |
| 绿蘑菇 | 黄昏 | 生吃大幅掉精神，熟吃回精神但损少量血 |
| 蓝蘑菇 | 夜晚 | 生吃回 20 血、12.5 饱食，但掉精神；熟吃回精神并损血 |

铲子可以直接挖蘑菇，但原片提醒这会延缓再生，不宜作为日常采摘的默认操作。蓝蘑菇生熟搭配可以平衡三维，不等于任何时候随便混吃都安全；先看当前哪项已经接近危险线。[P04 03:30–04:48 仙人掌和三种蘑菇](../../../../vn-resources/bilibili/BV1Fy4y1F79r/p04/video.mp4#t=210,288)

用强制攻击配合自动攻击，追到人物和蝴蝶影子接近重叠再出手，不是不断点远处蝴蝶。翅膀可回 8 血、9 饱食；黄油回复更高但掉率低，不应把它列为稳定回血计划。[P04 02:22–03:30 摘花、打蝴蝶与黄油](../../../../vn-resources/bilibili/BV1Fy4y1F79r/p04/video.mp4#t=142,210)

### 蜘蛛构成的食物与恢复循环

白天踩巢边蛛网，引出少量蜘蛛后退到网外，再打单只普通蜘蛛；在网内打会引出更多蜘蛛和战士。怪物肉用于肉丸，腺体用于治疗药膏，蜘蛛丝用于帐篷、鸟陷阱和钓竿。打掉三级巢得到可移植的巢，才便于在长期活动区附近建立供应。

淡水钓竿有耐久，池塘周边还有白天青蛙、沼泽黄昏和夜晚蚊子；冬季普通池塘结冰无法继续钓。海水钓竿不能拿去钓池塘，别把两种竿当成通用工具。海上龙虾窝黄昏刷龙虾，收线后保留活体再入锅。[P05 04:10–05:44 鸟笼与两类钓鱼](../../../../vn-resources/bilibili/BV1Qp4y1M7XB/p05/video.mp4#t=250,344)

## P06 基地建设篇

### 选址：近资源，但别把危险源放在家门口

基地把昂贵且不可随身移动的建筑、暂时用不到的材料与恢复设施集中起来。选址同时检查安全、附近补给和去重要地点的距离，不是看到某种地皮就必须定居。

- 黑色陨石痕迹提示陨石区，落石可毁建筑，不能因矿多就把家建进去。
- 麋鹿鹅巢附近有春季风险，池塘白天有青蛙，牛群有发情风险。
- 洞口方便取荧光果，但黄昏刷蝙蝠，基地要留出距离。
- 基础资源、猪王等常用地点要便于往返；实在拿不准，原片建议出生地附近作为低门槛起点，而不是声称所有世界出生地都最优。

### 建设顺序与稳定回复

**炼金引擎 → 石头火坑 → 烹饪锅 → 视材料补晾肉架、冰箱 → 帐篷/凉棚 → 鸟笼**。引擎解锁原型，火坑照明、取暖、烤食物，锅让低价值原料转成料理。锅需 **6 树枝、3 石砖、6 木炭**；木炭靠烧树后砍焦木获得，操作地点离基地足够远，不能为做第一口锅先把整个家烧了。

发条怪掉齿轮，可做冰箱延长食物保存。蜘蛛把肉丸、药膏、睡眠和鸟蛋路线串起来：引出单只蜘蛛 → 分别利用怪物肉、腺体、丝 → 保持饱食 → 睡眠回另外两维 → 鸟笼做即时回血料理。[P06 02:44–05:42 基础建筑与回复循环](../../../../vn-resources/bilibili/BV1Hr4y1R7sD/p06/video.mp4#t=164,342)

### 移植、防灾与功能分区

草与树枝移到家附近，草需要施肥；便利不是无限再生，还要维护。避雷针管闪电，雪球机用于处理火灾，两者不能互相替代。

## P08 驯服野牛篇

### 牛铃、顺从值与驯化度是三件事

牛铃绑定后，牛跟随的是牛铃；把铃带在身上才能持续跟随。每个玩家只能持有一个绑定铃。**绑定不等于驯服**：野牛顺从值低，直接上鞍可能挨打。先喂食提高顺从，再上鞍、骑乘；草和树枝也能喂，喂一次增加顺从，不代表饱食能维持一整天。

顺从值决定当前能否上鞍、骑乘：原片给出的门槛是超过 10 可上鞍、超过 40 不主动甩鞍、超过 50 可骑乘；驯化度决定骑乘持续时间和最终驯服。被甩下不必立即判断为牛铃绑定失败，可能只是当前驯化程度低。牛可自然回血，食物对它的回血效果也高，原片以蓝蘑菇回血示范；玩家骑牛战斗使用牛的攻击和承伤机制，不能套成玩家自己拿火腿棒的伤害。[P08 00:34–02:42 绑定、喂食、上鞍与两种属性](../../../../vn-resources/bilibili/BV1dM4m1R7XQ/p08/video.mp4#t=34,162)

### 两条驯化路线与资源账

牛**有饱食或正在被骑乘**时提高驯化度，两项不能叠加加速。原片按每天约 5% 讲解，连续维护约二十天；牛每日耗 300 饱食，草树枝虽然能喂，逐个喂来填肚子很浪费。

- 喂饱路线：四根树枝煮一份蒸树枝，每天按原片示例喂三份，约二十天需 240 根树枝。操作简单，但还要准备骑乘所需顺从。
- 骑乘路线：先用数日喂养提高初始驯化，随后跑图、采集尽量骑牛；砍树挖矿等必须下牛时补少量食物，使短暂离鞍期间也有饱食。时间管理更细，但减少持续供粮压力。

饥饿时顺从掉得更快，所以骑乘路线仍要频繁喂廉价物品，如花瓣、蕨叶、荧光果；“牛饿着也能靠骑提升驯化”不是“不必再喂”。过量喂食又可能损失驯化度，不能为了顺从一直塞到牛过饱。用多余海象牙制作刷子，每天刷毛增加驯化与顺从，可进一步缩短周期。[P08 02:42–05:08 饱食、骑乘与刷毛](../../../../vn-resources/bilibili/BV1dM4m1R7XQ/p08/video.mp4#t=162,308)

### 驯化完成与能力倾向

达到完全驯化会出现特效，之后需要继续维护，不能长时间丢着不管。完成前，攻击/受击提高战斗倾向，骑乘提高骑行倾向，高饱食及过量喂养影响肥胖倾向；只有某项足够突出才形成对应倾向，混合训练不一定自动得到战牛。**倾向在完全驯化时定型**，之后换鞍不等于换牛类型。

| 牛类型 | 原片特点 | 适合怎样使用 |
| --- | --- | --- |
| 普通牛 | 顺从下限 80，使用省事 | 日常代步、普通战斗 |
| 骑行牛 | 基础移速 8，攻击 25，顺从下限 95 | 已有自身战力、主要要交通工具的角色 |
| 战斗牛 | 基础攻击 50，顺从下限 45 | 战斗输出更高，但需要补喂才能方便骑 |
| 肥胖牛 | 移速较低，攻击 20，顺从下限 60，附近有回精神效果 | 原片不推荐作为效率优先的主力坐骑 |

不要把“所有完全驯化牛顺从下限都是 80”当通则，原片后半段已按类型修正。[P08 05:08–08:30 倾向训练与各类型比较](../../../../vn-resources/bilibili/BV1dM4m1R7XQ/p08/video.mp4#t=308,510)

### 鞍具：看攻击次数，不只看面板

基础鞍提供 40% 移速；战争鞍提供 25% 移速和 16 攻击；闪亮鞍提供 55% 移速，蝴蝶翅膀用量大，可考虑建造护符降低材料消耗。制作贵鞍前先明确牛的用途。

普通牛加战争鞍可达约 50 攻击，日常较省喂食；战牛加战争鞍到 66 攻击，但某些小怪所需攻击次数并没有减少，日常可以选速度鞍，面对高血量目标再换战鞍。骑行牛以跑图为主，配闪亮鞍。换鞍要使用相应拆鞍工具和操作，不是把装备直接丢在牛旁边。[P08 08:30–09:58 鞍具属性与搭配](../../../../vn-resources/bilibili/BV1dM4m1R7XQ/p08/video.mp4#t=510,598)

## P09 种地入门篇

[P09 种地入门 · 完整原片](../../../../vn-resources/bilibili/BV1ew411x7Za/p09/video.mp4#t=0,678) · [在 B 站观看种地入门篇](https://www.bilibili.com/video/BV1ew411x7Za/)

### 开田与压力：在下一次生长前补救

科学机器解锁耕地机，部署成耕地，一台可开四次；铲掉杂物、锄头开坑、把种子种进坑。普通落鸟的随机种子用于起步，冬季获取不便，尽量秋季准备。研究植物、肥料可解锁园艺图鉴，先驱帽便于查看，不需要先做远古高级帽子才能种田。

植物生长时累计压力，压力越多，生长慢、种子产量少。每阶段需要重新满足条件，不能开田时浇一次、对话一次后直到收获都不管。重要补救时机是进入下一阶段之前。[P09 00:26–02:10 开田、种子与压力机制](../../../../vn-resources/bilibili/BV1ew411x7Za/p09/video.mp4#t=26,130)

| 压力来源 | 操作检查 | 常见误判 |
| --- | --- | --- |
| 水分 | 地皮颜色与水量，按阶段补水 | 刚开的田并没有自动满水 |
| 养分 | 粪肥、堆肥、催长剂分别检查 | 一个肥料不能同时补足三种养分 |
| 杂草/杂物 | 铲掉杂物和长出的杂草 | 只收作物，不理旁边杂草 |
| 季节 | 看当前作物适应季节 | 混种比例对了，就忽略其中一种不应季 |
| 家族 | 周围保留足够同类，通常同类总数至少四株 | 混种每种只有三株，也以为能成大果 |
| 拥挤 | 每块地皮别超过十株 | 为增加产量把一格塞满 |
| 照料 | 每阶段对话或范围音乐照料 | 种下时对话一次便停止维护 |

### 水与三类肥料

原片按每次浇水增加 25、四次到 100 上限说明，新手先每天检查并补满；作物耗水不同，天气也影响维护频率。可多做几把水壶，一次到池塘全部灌满，再回基地浇田。[P09 02:10–03:12 水壶和地皮水分](../../../../vn-resources/bilibili/BV1ew411x7Za/p09/video.mp4#t=130,192)

三类养分独立储存；作物既消耗某些养分，也生成另一些。原片用土豆、番茄示范，不能只记“施肥越多越好”而忽略所缺类别。

- 粪肥：牛便便、猪便便。疯猪连续吃地上的荧光果可产大量粪肥；便便桶把材料集中成多次可用的肥料，骨片还可来自腐烂鱼，别只认沙漠的有限骨头。
- 堆肥：腐烂食物、臭鸡蛋，堆肥桶可转化有机原料；多余荧光果也能用于相关循环。
- 催长剂：腐烂鱼效果有限；海上瓶子用于制作催长剂起子，原片演示随腐败增强，完全腐败后得到多次可用的超级催长剂，耗完返还瓶子。取得瓶子本身需要航海，不能把它列为第一天种田的必要条件。

[P09 03:12–04:54 养分、猪粪、堆肥与催长剂](../../../../vn-resources/bilibili/BV1ew411x7Za/p09/video.mp4#t=192,294)

### 起步先扩种，不要直接追大果

随机种子可能长杂草，不能长巨大作物。先种下、收一轮，把目标果实喂鸟笼换专属种子。稀有作物只有一颗种子时单开一块田，控制好主要压力，收果和额外种子，再把果实换种子，逐轮扩大；直接把仅有一颗种子吃掉或混在一大片乱种田里，会拖慢专属种子积累。[P09 04:54–07:24 杂草、家族、照料与扩种](../../../../vn-resources/bilibili/BV1ew411x7Za/p09/video.mp4#t=294,444)

### 单种、配比、轮作分别解决什么问题

**单种法：** 同一种作物集中种，方便判断季节、家族和需要的肥料。原片示范每地皮九坑、应季火龙果，及时浇水、施肥、照料。熟火龙果回血；火龙果加三树枝可做火龙果派，用于饱食和血量回复。专用需求也适合单种，例如厨师只想收辣椒，而不想为配比额外经营大量番茄。[P09 07:24–08:22 单种火龙果](../../../../vn-resources/bilibili/BV1ew411x7Za/p09/video.mp4#t=444,502)

**配比法：** 用不同作物养分的消耗与生成互补。原片示例每地皮四土豆加四番茄，数量 1:1，既不过度拥挤、又满足各自家族，减少额外施肥，只维护水分与照料。三种作物配比时，每种只三株可能产生家族压力，可在邻地补同类；检测看距离，不要求同类只能在同一块地皮。[P09 08:22–09:36 土豆番茄与家族补足](../../../../vn-resources/bilibili/BV1ew411x7Za/p09/video.mp4#t=502,576)

**配比失效条件：** 两种生长速度不一致，养分在各阶段的释放和消耗错开，就算整轮总量相等，也可能在某阶段先缺肥。番茄与土豆的应季条件不同，因此配比必须同时看季节与同步生长，不能全年机械重复同一张种植表。

**轮作法：** 先把所需养分补足，整块种土豆，让它消耗粪肥、积累堆肥和催长剂；下一轮种番茄消耗这些积累，再产生下一轮可用养分。原片用八株、每阶段用量解释轻微最后阶段缺肥仍可能允许大果；重点是可接受的少量压力与养分循环，不是“轮作永远零压力”。非应季作物仍生长较慢，不能保证每季两种都巨大。[P09 09:36–10:58 季节差异、轮作与选择](../../../../vn-resources/bilibili/BV1ew411x7Za/p09/video.mp4#t=576,658)

### 从作物回到生存目标

土豆、番茄烤熟可用于回血；番茄配冰和蔬菜做蔬菜鸡尾酒，土豆配树枝及填充物做花式回旋块茎，各有回精神用途。种田方法取决于自己缺什么：急需回血先稳定能收获的果实，需要专属食材再单种，要减少肥料管理再配比或轮作。别为了大果把日常食物、照明与危险处理全丢掉。[P09 08:54–09:16 作物的恢复用途](../../../../vn-resources/bilibili/BV1ew411x7Za/p09/video.mp4#t=534,556)

### 出海前配置与漏水处理

船套件放在能通向外海的位置，不要在封闭小水域造好才发现出不去。出海会耗多天，先带食物、冰箱、提灯、荧光果、桨、船补丁；原片还建议排箫应对海盗。浮木岛找到浮木后可升级浮木桨，造价与耐久更适合长期航行。

浅海较便于返岸，原片也用于避开更麻烦的礁石和鲨鱼。路线不要只盯着海水颜色，白天光照、缩放和显示设置可能影响辨认；在地图上记录已走边界，减少重复航行。[P10 01:58–03:06 月岛线索与浅海路线](../../../../vn-resources/bilibili/BV1oF411S7zw/p10/video.mp4#t=118,186)

### 水中木、盐矿与地图方向

指南针辨方向后，原片优先查大陆西南方向海岸附近；若西南海域空间太小，还会考虑东北海域。它是提高优先搜索区域的经验，不是输入方向就定位的固定坐标。不同地图、世界生成版本及自定义设置可能改变结果，查完候选区要回到实际海图，而非无限向西南划。[P10 03:06–03:54 水中木和盐矿的优先搜索区](../../../../vn-resources/bilibili/BV1oF411S7zw/p10/video.mp4#t=186,234)

### 中海：礁石、鱼点、鲨鱼与任务定位

礁石多，不赌“刚好能从中间挤过”；看到阻挡提前改航向，给船惯性留空间。中海有更大的鱼与地图可见的固定鱼点，但不能把钓鱼收益当成无风险航行的证明。遇到岩石鲨优先跑或用传送手段处理，别在不熟悉船战时硬拼。

帝王蟹直接靠漫无目的扫海效率低；原片更推荐完成档案馆相关任务拿天体探测仪，未发掘月岛天体祭坛时也可辅助相关定位。把“去找主线目标”与“随手收集海上资源”分开规划，补给不够先返岸。[P10 03:54–04:56 中海资源与任务工具](../../../../vn-resources/bilibili/BV1oF411S7zw/p10/video.mp4#t=234,296)

### 深海、隐士岛与猴岛

零散礁石尚可提前微调绕过，密集礁石群整体绕行；即使补丁很多，也不建议把反复撞船当路线。漂流瓶可标记隐士岛，比扫完整片深海更直接。

猴岛有可移植香蕉、芦苇，但附近海盗猴会登船抢东西；直接击杀还有诅咒负担。猴岛需要较大深海、不能太近世界边缘，也会受其他地形影响，但原片最后承认海区形状并非完全可预测。原片画面补充三个候选区：深海空间足够时优先西南；西南被盐矿、水中木挤占时兼查东北，并关注其靠东南的一侧；前两处深海都太小再考虑东南。作者同时强调中深海混合使形状不可精确预测。建议与世界边缘保持约三个屏幕距离绕行，把生成线索作为候选区筛选，而不是保证找到的公式。夜间照明、食物和修船物品不足时先返航，别因为已经出海很久就继续盲找。[P10 04:56–06:52 礁石、漂流瓶与猴岛](../../../../vn-resources/bilibili/BV1oF411S7zw/p10/video.mp4#t=296,412)
