# 羽毛球基础精要：15 P 学习笔记

正文与笔记的唯一内容源是 `教程.md`；`index.html` 是它生成的离线阅读页面。浏览器用于看文字和对应原片，没有浏览器写入或个人状态存储，也不读取 `lesson.json`。

## 阅读与编辑

直接打开 `index.html`。左侧按 P 展开动作小节，顶部搜索正文和小节标题，文字中的片段在右侧打开，阅读位置保持不动。右侧“原片”选择器可切换全部 15 P；每个片段使用所在 P 的时间，不使用全系列累计时间。顶部“播放来源”全局切换全部视频：本地视频使用素材仓库的 MP4，可在片段终点暂停与循环；B 站视频使用官方内嵌播放器，按分 P 和起始时间打开。切换来源会保留当前片段的位置，不修改 Markdown。收起画面后文字区域扩展；窄屏按需打开底部画面。

在 Neovim 等编辑器中修改 `教程.md`，笔记直接追加在对应段落旁。例如：哪里卡住、自己的握拍与击球位置、同伴站位、下次只改哪一个动作。

在本目录运行 `node build.cjs` 后刷新页面。持续编辑用 `node build.cjs --watch`；保存 Markdown 会重新生成 HTML，仍需刷新页面。构建只写 `index.html`，不会改动笔记。无需安装网页依赖、启动服务或登录。

快捷键：`Esc` 收起画面，`[` / `]` 切换上一处 / 下一处视频片段。

## 添加视频片段

使用普通 Markdown 链接，例如：

```markdown
[P07 06:40–07:20 落地与制动](../../../../vn-resources/bilibili/BV17t411j7Qr/p07/video.mp4#t=400,440)
```

时间以秒表示，形式为 `#t=起点,终点`，同一个入口随全局选择使用本地或 B 站播放。原有截图入口已转换成附近的视频片段，范围大致为原截图时间前 10 秒至后 20 秒，并限制在各 P 的视频时长内；这些范围是复习定位，不能当作讲师完整讲解的精确边界。原始截图仍保留在素材仓库。

每一 P 的完整原片入口也写在 Markdown 中；选择器从这些链接生成，不依赖另一份内容数据。保留 `P01 … · 完整原片` 这样的标题和从 0 秒开始的 MP4 片段链接即可。

渲染支持标题、段落、粗体、斜体、链接、表格、单层列表、引用、行内代码与代码块；不支持任意 HTML、复杂嵌套列表或表格单元格中的竖线转义。写普通 Markdown 即可。

## 分享到网站

### 使用现有 sync-blog.py 发布

没有“分享”按钮。仓库只保存源码，生成文件由 GitHub Pages CI 创建，不需要在发布前本地导出。使用现有 docs/pub/sync-blog.py 同步源码，再按原流程推送目标仓库即可。CI 在 Jekyll 前运行 node docs/learning/build.cjs --publish，生成默认使用 B 站视频的页面；Markdown 原文直接引用 教程.md。

首次新增源码需要由你纳入 Git 跟踪，发布审计才会包含它们。生成的 index.html、share/ 已被忽略，不保存、不提交。构建命令保留用于临时验证；验证后删除产物。网站入口为 /learning/BV17t411j7Qr/。源码仍是本目录的 教程.md。

### 临时验证分享目录

运行 `node build.cjs --share`，将生成的 `share/` 目录整体上传到静态网站，入口为 `index.html`。目录包含教学正文及可下载的 Markdown 副本，不包含 MP4，不依赖同级素材仓库；再次构建会更新导出文件。当前教程不依赖截图，分享目录无需携带图片。

分享版在右侧使用 [B 站官方外链播放器](https://player.bilibili.com/)，自动传入原视频编号、分 P 和起始秒数。每个片段都提供“B 站对应画面”。本地版与分享版均提供全局“播放来源”选择器。通过 HTTP/HTTPS 访问普通版时，默认使用在线播放，但发布仍推荐完整的 `share/`。

B 站在线播放器受原站可用性、登录和播放限制影响；不能在本页面精确控制片段终点或循环，需要时通过旁边的链接打开原站。片段结束暂停、循环仍适用于本地 MP4。导出的 Markdown 是阅读副本，编辑仍使用本目录的 `教程.md`。页面保留原片来源链接；引用原站播放器不代表获得了截图或教程的传播授权。

## 本地文件与同步

| 文件或目录 | 用途 |
| --- | --- |
| `教程.md` | 教学正文、画面链接与个人笔记 |
| `template.html` | 阅读界面和 Markdown 渲染 |
| `build.cjs` | 单向生成与监听 |
| `index.html` | 可直接打开的生成页面 |
| `verify.cjs` | 资源、构建方向和浏览器交互检查 |
| `download.ps1`、`download-tail.ps1` | 本次公开接口下载脚本；链接与可用画质可能变化 |
| `extract.ps1`、`ocr.ps1` | 抽帧与 Windows OCR 辅助脚本 |
| 同级 `vn-resources/bilibili/BV17t411j7Qr/` | 15 P 视频、截图、联系表、原始识别文本与来源信息 |

不同机器上把 `vn` 和 `vn-resources` 放在同一父目录即可；路径不依赖盘符。本地视频模式依赖素材仓库里的 MP4；B 站视频模式不读取本地视频。分享目录不含 MP4，访客应使用 B 站模式；若选本地模式，需要自行提供相同相对路径的 MP4。尚未配置云盘或自动同步。`manifest.json` 记录素材大小和 SHA-256，方便同步后校验。

## 来源与整理边界

原片：[羽毛球基础精要（全集）高清晰度](https://www.bilibili.com/video/BV17t411j7Qr/)，上传者“大师兄哔哩哔哩”。来源接口列出 15 P、总计约 3 小时 27 分钟；上传者不等于各集讲师。

全部 15 P 都完成了本机 faster-whisper small 中文语音识别，再结合内嵌中文字幕 OCR、章节标题与相应画面整理。所有 P 都下载了完整视频与音频。公开字幕接口未返回独立字幕；OCR 与 ASR 原始文本保留在资源目录，可能有错字、重复、繁简混用和近似时间。

正文保留概览，并逐项展开准备姿势、脚步顺序、拍面与发力变化、学员纠错、战术条件及后续衔接。重复示范不逐次复述，讲师实际讲解的区别与纠正点分别保留；不是逐字转录，也没有声称逐帧看完全部视频。文字中的问题速查、自查提示、连续回合拆解和跨章节关联属于整理者归纳。片段边界近似；细微动作以原片连续画面为准。

旧教学片的发球高度与停顿说法已在 P09 单独校正，并链接 BWF 官方发球条款。讲师示范中的腿部角度与距离没有转换成人人必须照量的标准；混双示例中的分工按实际能力理解。

`node verify-share.cjs 9226` 另外检查分享版的视频入口、15 P 与时间点引用、不加载本地 MP4，以及关闭画面时卸载外链播放器；不保证 B 站在每个访问者的网络与登录条件下均可播放。
