# 羽毛球基础精要

原片：[在 B 站观看《羽毛球基础精要（全集）》](https://www.bilibili.com/video/BV17t411j7Qr/)，共 15 P。

握拍与发力 → 单项击球 → 到位与回动 → 发接发 → 单双打配合。先把一次击球做完整：看清来球、移动到位、触球、恢复准备；再把下一拍接进去。以下左右脚与持拍方向沿用原片的右手持拍示范，左手持拍者镜像理解。

## 按问题查找

| 卡住的现象 | 优先检查 | 对照章节 |
| --- | --- | --- |
| 手很用力，球却打不远 | 握拍是否一直攥死；是否只摆大臂；是否退到球后方 | [P01 握拍](#part-01)、[P02 挥拍](#part-02)、[P03 高远球](#part-03) |
| 高远、吊球、杀球一开始就被看穿 | 三种球的转身与举拍准备是否一致；区别是否留到触球前 | [P03 后场击球](#part-03) |
| 上网够不到，或者冲过去站不住 | 前几步是否及时；最后一步是否有距离与制动；是否把拍子带到前方 | [P07 基本步法](#part-07)、[P08 连贯步法](#part-08) |
| 后场打完来不及接网前 | 击球落地后重心是否已经向前；是否一直停在后场看球 | [P08 连贯步法](#part-08)、[P15 跳起技术](#part-15) |
| 接平快发球总是慢半拍 | 准备重心是否偏高；肩和大臂是否摆得太大 | [P10 接发球](#part-10) |
| 双打两个人都去抢同一球 | 是否明确进攻前后、防守左右；中路是否有人联防 | [P13 双打站位](#part-13)、[P14 杀中路](#part-14) |
| 杀球很多却拿不到主动 | 落点是否迫使对方被动；是否衔接封网；伙伴是否补住空当 | [P11 单打战术](#part-11)、[P14 前封后攻](#part-14) |

## P01 · 握拍：先能换拍面，再谈用力

[P01 握拍 · 完整原片](../../../../vn-resources/bilibili/BV17t411j7Qr/p01/video.mp4#t=0,178) · [在 B 站观看 P01](https://www.bilibili.com/video/BV17t411j7Qr/?p=1)

**正手握拍**像握手：虎口对准拍柄的窄面，食指与中指略分开，掌心与拍柄之间留出活动空间。上面的拇指、食指帮助控制方向，下面三指在触球时参与握紧发力。准备阶段松、击球瞬间紧，避免从头到尾死握。

[P01 正手握拍近景](../../../../vn-resources/bilibili/BV17t411j7Qr/p01/video.mp4#t=20,50) [P01 00:20–01:10 正手握拍](../../../../vn-resources/bilibili/BV17t411j7Qr/p01/video.mp4#t=20,70)

**反手握拍**在正手基础上转动拍柄，用拇指支撑拍柄宽面，便于小动作向前顶出。换拍面靠手指调整，别把整个手臂绕一大圈。P03 的反手后场球还示范了拇指靠棱面的变化，不能把所有反手技术都固定成同一个握法。

[P01 反手拇指位置](../../../../vn-resources/bilibili/BV17t411j7Qr/p01/video.mp4#t=70,100) [P01 01:10–01:45 正反手转换](../../../../vn-resources/bilibili/BV17t411j7Qr/p01/video.mp4#t=70,105)

| 原片握法 | 识别点 | 复习时看什么 |
| --- | --- | --- |
| 正手 | 虎口与窄面配合，食指留空间 | 拍面是否能自然转动 |
| 反手 | 拇指向前支撑宽面 | 向前顶拍时，手腕与拍面是否协调 |
| 锤式 | 食指与中指靠近，强调握紧发力 | 是触球时握紧，还是准备时已经僵住 |
| 钳式 | 拇指、食指控制较明显，适合精细网前动作 | 小动作能否改变拍面、控制出球 |

[P01 01:45–02:58 锤式与钳式握拍](../../../../vn-resources/bilibili/BV17t411j7Qr/p01/video.mp4#t=105,178)

### 正手握拍的建立与检查

1. 先用另一只手扶住拍子，让拍面竖起来，再让持拍手按握手的方向包住拍柄。先看拍面的方向，再检查手的位置，避免拍子已经躺平，手仍按原来的位置硬握。
2. 虎口与拍柄窄面配合。食指、中指分开，原片用“约一个手指的距离”帮助识别；不是五指一起紧贴着绕住拍柄。
3. 检查掌心有没有活动空间。拍柄完全压在掌心里、整只手攥死，手指转拍与线路变化都会受限制。空间不是让拍子松到会滑落，而是保留调整余地。
4. 再检查分工：拇指、食指帮助调整拍面，下面三个手指参与握紧与发力。讲师讲的是控制和发力的侧重点，实际击球要把它们接成同一个动作。

这里最容易漏掉的是**握法并非只负责把拍子拿住，还负责让拍面可以变化**。同一只拍子若不能在手中小幅调整，就会把正反手转换、网前切球等动作变成整个手臂的大动作。原片在握拍讲解中直接把“掌心空间”与“出球变化”联系起来。

[P01 00:22–01:08 虎口、指间距离与掌心空间](../../../../vn-resources/bilibili/BV17t411j7Qr/p01/video.mp4#t=22,68)

### 反手换握与两种特殊握法

换成反手时，把拇指支撑点转到拍柄宽面，让它能在向前顶拍时发挥作用；演示后又转回正手，说明这是一种可以来回调整的握拍。复习时要同时看“转到哪里”和“能否转回来”，不要只复制一张反手握拍静态图。

锤式握拍把食指、中指相对靠近，讲师用它强调较集中的力量型发力；钳式握拍让拇指、食指夹控更明显，用于网前细小变化。它们不是把整场球都改成一种固定握法，而是不同处理条件下的控制方式。

| 容易混淆的地方 | 原片区别 | 复习动作 |
| --- | --- | --- |
| 正手与锤式 | 普通正手保留食指、中指之间的空间；锤式两指靠近 | 连续比较两种握法，观察握紧时的指位 |
| 反手与钳式 | 反手突出拇指支撑拍柄；钳式突出拇指、食指的夹控 | 看是向前顶拍，还是精细调整拍面 |
| 静态握拍与击球握拍 | 准备阶段需要调整，触球时需要集中发力 | 不带球先练转拍面，再加短促握紧 |

## P02 · 挥拍：把手指、小臂和身体接起来

[P02 挥拍 · 完整原片](../../../../vn-resources/bilibili/BV17t411j7Qr/p02/video.mp4#t=0,235) · [在 B 站观看 P02](https://www.bilibili.com/video/BV17t411j7Qr/?p=2)

原片先拆成三个动作练习，再加入脚步。**正手与反手的旋转挥拍**都先把肘的位置建立起来，通过小臂转动带出拍面；反手示范从身体前方提肘、向上挥出。下面三指参与瞬间握紧，上面两指保留控制。观察重点是拍面怎样由侧面对准击球方向，而不是只看拍头走了多远。

[P02 正手旋转挥拍](../../../../vn-resources/bilibili/BV17t411j7Qr/p02/video.mp4#t=30,60) [P02 00:20–01:20 正手旋转](../../../../vn-resources/bilibili/BV17t411j7Qr/p02/video.mp4#t=20,80) [P02 01:20–02:15 反手旋转](../../../../vn-resources/bilibili/BV17t411j7Qr/p02/video.mp4#t=80,135)

**摆臂挥拍**先侧身，肘抬到较高的位置、持拍手举起，在头上方完成击球，再自然收至身体另一侧。加脚步后，转身、举拍与重心移动应连贯；先把动作做顺，再提速。不要把“退步”“举拍”“挥拍”拆成彼此等候的三件事。

[P02 举拍与侧身](../../../../vn-resources/bilibili/BV17t411j7Qr/p02/video.mp4#t=130,160) [P02 02:15–03:55 摆臂及脚步配合](../../../../vn-resources/bilibili/BV17t411j7Qr/p02/video.mp4#t=135,235)

### 正手旋转挥拍：先识别拍面怎样转正

原片把这一组动作称为“内旋挥拍”。从正手握拍开始，手臂放下、肘朝前，在出手时用小臂转动带出拍面，使拍面正对向前的击球方向。练习重点是**每次挥出去都能把拍面转正**，不是拍头向前走了就算完成。

分开看两个部分：一是肘与手臂建立方向，二是小臂转动让拍面改变朝向。若只用整条手臂往前摆，拍面可能仍斜着；若只在原地扭手，又没有挥出去的方向。先慢做，确认拍面，再逐渐连贯。

[P02 00:10–01:02 正手旋转分解](../../../../vn-resources/bilibili/BV17t411j7Qr/p02/video.mp4#t=10,62)

### 反手旋转挥拍：从腹前组织，提肘向上

原片称为“外旋挥拍”：先转身，肘向前，再向上提起；拍子从身体腹前一带向上挥出。肘的位置是动作的引导点，不是让拍头先绕到背后，再拖着整条胳膊向上甩。

脚步示范加入弓步，讲师一边抬肘挥拍，一边提醒下面三个手指发力、上面两指保留控制。复习时看抬肘、拍面转动与握紧是否在同一次挥拍中配合，别把它们拆成先后等待的口令。

[P02 01:04–02:18 反手挥拍与弓步配合](../../../../vn-resources/bilibili/BV17t411j7Qr/p02/video.mp4#t=64,138)

### 摆臂挥拍的顺序与常见断点

1. 看准来球方向，先抬脚、转身，建立侧向准备。
2. 双臂举起；原片用肘高于眼部、持拍手高于头部作示范口令。比较的是举拍是否到位，不是要求每个人把关节角度固定成一个数字。
3. 手臂向来球方向挥出，把前面旋转挥拍接进来；触球时拍面要能对正。
4. 挥完后自然落到身体另一侧、左手附近，保持连贯，不把拍头僵停在空中。

| 动作断点 | 会漏掉什么 | 看哪一段 |
| --- | --- | --- |
| 先跑完，再举拍 | 移动过程中的击球准备 | 最后的手脚配合示范 |
| 手举起，身体仍正对球网 | 侧身与身体转动 | 起始抬脚转身的分解 |
| 只摆大臂，拍面没有转正 | 小臂旋转与拍面控制 | 正手旋转分解 |
| 击球后停在头上 | 自然随挥与下一拍准备 | 完整摆臂挥拍 |

[P02 02:22–03:18 举拍与自然收拍](../../../../vn-resources/bilibili/BV17t411j7Qr/p02/video.mp4#t=142,198) [P02 03:20–03:52 加入脚步的完整挥拍](../../../../vn-resources/bilibili/BV17t411j7Qr/p02/video.mp4#t=200,232)

## P03 · 后场击球：高远、平高、吊球与杀球

[P03 羽毛球基础精要 · 完整原片](../../../../vn-resources/bilibili/BV17t411j7Qr/p03/video.mp4#t=0,1846) · [在 B 站观看 P03](https://www.bilibili.com/video/BV17t411j7Qr/?p=3)

### 正手、反手与头顶高远球

**正手高远球**先判断落点、侧身到位，举拍准备，击球时把身体转动、小臂与手指握紧接起来。原片强调举拍时肘与手的位置，不要把拍子倒在身体外侧；触球后自然随挥、回到下一拍准备。球打不远，先检查到位和击球点，再检查发力，别只增加大臂的摆幅。

[P03 高远球准备姿势](../../../../vn-resources/bilibili/BV17t411j7Qr/p03/video.mp4#t=130,160) [P03 00:30–04:30 正手高远球](../../../../vn-resources/bilibili/BV17t411j7Qr/p03/video.mp4#t=30,270)

**反手高远球**先转身，手臂从身体前方组织动作，提肘、转小臂，集中在触球瞬间发力。原片将拇指放在拍柄棱面附近，保留角度变化。常见错误是手臂拖到身体后方、动作很长却错过击球时机；后场反手的关键是紧凑与及时，不是追求巨大的随挥。

[P03 反手举肘](../../../../vn-resources/bilibili/BV17t411j7Qr/p03/video.mp4#t=320,350) [P03 04:40–07:30 反手高远球](../../../../vn-resources/bilibili/BV17t411j7Qr/p03/video.mp4#t=280,450)

**头顶高远球**用于绕到反手侧、仍用正手拍面处理的来球。与正手基本发力相通，但转身和退步方向不同。手脚同时组织、保持平衡，别只向侧面伸手够球。P07 专门补充了头顶区域步法。

[P03 07:30–09:45 头顶高远球](../../../../vn-resources/bilibili/BV17t411j7Qr/p03/video.mp4#t=450,585)

### 平高球：用速度压缩对方时间

平高球的弧线较平、节奏较快，原片用它说明进攻和转换。与高远球相比，击球准备仍须到位，但触球阶段的小臂、手腕动作更快、更集中；不能因为追求平，就在身后勉强平推。头顶位置也有同类变化，打完仍要恢复平衡。

[P03 平高球挥拍](../../../../vn-resources/bilibili/BV17t411j7Qr/p03/video.mp4#t=650,680) [P03 09:45–13:00 平高球](../../../../vn-resources/bilibili/BV17t411j7Qr/p03/video.mp4#t=585,780)

### 吊球：共用准备，最后改变拍面与出球

**高远、吊球、杀球的准备尽量一致**：侧身、举拍、到位，不要在准备阶段直接告诉对手要吊球。正手吊球触球时控制拍面与切击方向，球应落在对方前场。原片先示范轻、慢的控制，再增加切击，不建议一开始就靠强力“砍”球找落点。

[P03 吊球拍面示范](../../../../vn-resources/bilibili/BV17t411j7Qr/p03/video.mp4#t=850,880) [P03 13:15–16:00 正手吊球](../../../../vn-resources/bilibili/BV17t411j7Qr/p03/video.mp4#t=795,960)

**头顶吊球**通过到位后的拍面变化控制直线、斜线。比较两种线路时看最后触球动作，而不是只看准备姿势；触球后继续自然随挥，不要突然停在头顶。

[P03 16:00–18:42 头顶吊球及线路](../../../../vn-resources/bilibili/BV17t411j7Qr/p03/video.mp4#t=960,1122)

**反手吊球**先有转身、举肘与紧凑触球，再谈直斜线。原片比较了拇指位置对拍面角度的影响：固定顶在宽面，斜线变化会受限制；靠棱面的握法保留转动空间。不要为追求线路，把手臂大幅拖向身后。

[P03 反手吊球拍面](../../../../vn-resources/bilibili/BV17t411j7Qr/p03/video.mp4#t=1230,1260) [P03 18:50–23:50 反手吊球](../../../../vn-resources/bilibili/BV17t411j7Qr/p03/video.mp4#t=1130,1430)

### 杀球：先把球向下打，再追求速度

杀球要有向下的出球方向。原片反复纠正的不是“再用力”，而是**提前退到球后方，击球点在身体前上方，触球时拍面形成下压方向**。如果击球点落在身后，再大的力也容易把球打平、打长。准备时放松，力量集中在触球瞬间，身体转动与挥拍连贯。

[P03 杀球击球位置](../../../../vn-resources/bilibili/BV17t411j7Qr/p03/video.mp4#t=1510,1540) [P03 24:05–26:35 正手杀球要领](../../../../vn-resources/bilibili/BV17t411j7Qr/p03/video.mp4#t=1445,1595)

正手直线与斜线、头顶直线与斜线都是同一基础动作上的拍面和线路变化。头顶区域要更及时地转身退步；跳起能提高击球位置，但须先有到位与落地回动，P15 再拆解。

[P03 26:35–27:18 正手直线示范](../../../../vn-resources/bilibili/BV17t411j7Qr/p03/video.mp4#t=1595,1638) [P03 27:18–27:54 正手斜线示范](../../../../vn-resources/bilibili/BV17t411j7Qr/p03/video.mp4#t=1638,1674) [P03 28:00–30:46 头顶杀球](../../../../vn-resources/bilibili/BV17t411j7Qr/p03/video.mp4#t=1680,1846)

| 想打的球 | 主要任务 | 自查 |
| --- | --- | --- |
| 高远球 | 把对方推到后场，给自己调整时间 | 到位、举拍、集中发力是否完整 |
| 平高球 | 用较快的飞行节奏压迫后场 | 是否因图快而丢掉击球点 |
| 吊球 | 控制前场，制造前后移动 | 是否保持准备一致、落点是否有质量 |
| 杀球 | 下压并衔接下一拍 | 是否真向下、打完能否继续上网或回动 |

### 正手高远球：手上三段，脚上同步转身

讲师先把发力部位讲清：下面三个手指握紧带动小臂、手腕，上面两个手指相对放松并控制拍子。接着把挥拍拆成准备、转身举肘、向前上方挥出三段：双手立起，拍子不要向身体外侧倒；对准来球方向转身，肘与持拍手举高；挥出去时小臂带出拍面旋转，击球后自然落回腰部。

脚上的补充是侧身时左脚配合转动，脚跟略抬，左膝与脚尖的方向随转身调整，让腰部转得过来。手脚要接成完整动作：身体已经转向来球，举拍却落在后面；或者手已举好，脚还拖着，都容易把击球准备拆断。

原片安排“先慢动作分解 → 连贯空挥 → 学员发球”的顺序，目的在于先识别挥拍和拍面，再把来球时机加进去。自查时可分别看：拍头准备方向、肘的位置、触球前有没有转正拍面、挥完是否能自然放松。

### 反手高远球：换握、前方提肘、集中发力

反手后场的握法与 P01 的基本反手示范并非原封不动相同：这里讲师把拇指放在拍柄的竖立面／棱面附近，食指、中指仍分开，下面三指参与主要发力，上面两指控制拍子。随后拍子向下组织，留在身体前方，肘向上提，手臂与小臂带出向上的击球动作。

讲师重点示范错误动作：肩与手臂被拉到身体后方、挥拍幅度过大，看起来很用力，却破坏了发力集中。正确示范强调在身体前上方完成主要动作，触球后放松下来。不能把“集中”理解为从头到尾把肩膀夹紧，它是触球阶段紧凑，而准备阶段仍须能组织动作。

### 头顶高远球：第一步转不过来，后面就被动

头顶区用正手处理反手侧上方的来球，所以转身方向与幅度变得更关键。讲师先解释：第一步没有把身体转过去，后面就容易被动；随后示范手和脚同时向后组织，不先走脚再补手，也不只伸手而身体停在原地。

第一步重心略低，保持平稳，为下一步移动留下余地。到位后向上击球，手上的发力仍延续正手高远的关键点。这里的“重心低一些”指准备与启动的稳定关系，不是越蹲低越好，也不能牺牲退步和举拍速度。

### 平高球：击球点与短促回收一起变

与高远球的长弧线相比，平高球更强调快速向前的出球。讲师用“发力以后有一点收回的感觉”解释触球后的小幅回收，避免手臂继续向前送得太长；同时比较击球点：相对更靠前，或者比高远球处理的位置略低，方便形成较平的出球。

这不是让人故意等球掉下来，也不是所有平高球都把接触位置放低。原片是在比较两种球的拍面和出球方向。要把“点略变”和“发力短、动作快”一起看：只改拍面、仍用很大的摆幅，节奏不够快；只加快挥拍、没有合适接触点，球容易失去线路。

头顶平高球沿用相同的集中发力，但转身幅度更大。讲师提醒小臂、手腕要配合，避免用过大的动作影响重心，打完仍能恢复准备。

### 正手吊球：先解决暴露意图，再解决切球力度

原片首先纠正“不转体就吊球”：对手从准备姿势便能看出你要打软球。处理顺序是先保持高远、吊球、杀球的共同转体准备，再在触球时放松，以手腕的小幅推进配合切击球头。

初练不要用过大的力量。讲师指出力量大而拍面控制不足，会把球打得过高或过远；先用慢一点、轻一点的动作把落点控制到对方前场，原片以发球前线以内的区域作目标。掌握后再增加切击力量，形成劈吊变化。

切击看的是球头侧方与底部的接触关系，不是对着球头正面大力打下去。直线与斜线也不能仅靠身体先朝向另一边暴露线路，要在共同准备里保留最后的拍面变化。

### 头顶吊球与反手吊球：不要只记线路名称

头顶吊斜线示范外侧滑切幅度较大，拍面相对倾斜；吊直线时内侧切击较小。转身、到位和共同准备仍然相近。讲师还纠正触球后在头上突然停拍，要求挥拍保持完整；完整随挥不等于把触球力量加大。

反手吊球先比较两种拇指位置：固定顶宽面，对直线较方便，斜线变化受限制；靠棱面则留出更多拍面调整。触球时手臂与球拍形成原片所示的 **V 字关系**，帮助控制向下的出球，而不是形成高远球向上送出的拍面。

初步练反手吊时，讲师允许把触球节奏放慢，用来找击球点；它是教学分解中的提示，不是每次实战都停拍等球。最后发力由手指、小臂与手腕配合，击球后放松，不能把手臂继续硬拖到身后。

### 热身、握拍与发球

开头示范颈、肩、腰、跨步及手腕脚踝活动，再复习正反手握拍。正手虎口对准拍柄侧面，食指与中指分开；反手在此基础上调整食指与拇指。发高远球示范左脚前、右脚后，先放球，身体重心向前转移，球拍从身体右侧挥出。短发沿用类似脚步，缩小动作、控制平推；反手短发换成反手握拍，右脚前、左脚后，向前小幅推出。

### 放网与勾球：步法相同，最后手法不同

正反手放网都先把拍子送到前方，最后跨步与手上动作配合，触球轻柔。原片先练最后到位姿势，再串右脚先跨、左脚交叉、右脚蹬跨三步，打完用垫步恢复。反手侧记得先换握拍，不能到触球时才想起转拍面。

勾球沿用上网步法，区别留在触球附近：正手向反手方向带切、反手向相反方向带切。**拍头走较平的线路**；向上撬容易过高，过分向下切容易下网。拍面随目标方向调整，动作柔和，不能只把球硬弹向斜线。

### 搓球与扑球：区分切球头和向前压球

搓球用小幅、柔和的切击控制球头，原片分别演示正反手拍面展开的方向，强调握拍不要太紧、动作不要太大。拍子早伸出，最后手上动作与脚步衔接；观察拍面怎样接近球头，别把搓球做成大臂推送。

扑球用于对方网前回球较高、自己能抢到主动的位置。原片有一步与三步到位示范，拍头抬起，紧凑向前并向侧方带出，避免挥拍碰网。扑球后的跟进也要保留控制，不是整个人撞向球网。

### 挑球与推球：向上解围和向前抢点

**挑球**从较低位置向前上方送出。正手示范强调向前上发力，不要把拍头带向身侧；反手示范换握拍、展开拍面，拇指参与向前顶拍。最后跨步要能稳住，别抬高身体、向前冲过头。

**推球**可从相似网前准备中突然向前点出。原片先给搓球的准备形态，再用手指与小动作把拍面转正向前推出；动作小、力量集中，区别于继续切球头的搓球。先判断自己是否能在较高、较主动的位置处理，不要把低点被动挑球和主动推球混为一谈。

### 发球分解：脚、放球与挥拍怎样相接

**正手高远发球**的脚位先摆成原片示范的丁字形：左脚前、右脚后，起始重心偏后腿。持拍手自然伸到身体右前方，左手持球略举起。放球后，球拍向身后展开，身体重心由后腿向前腿移动，转身并从右侧向前挥；触球阶段拍面转正向前上方发力，打完自然收到左上方。

这里“先放球”与“再击球”是一个连续配合，不能把球抛得很远再用手去追。观看分解时分别跟踪左手放球处、拍头后摆、身体转动和触球方向，就能看到为什么只动手、重心不走，会缺少完整的发球动作。

**正手短发**沿用脚位和持球准备，区别是持拍手提起并用较小动作平推过去。**反手短发**则右脚前、左脚后，后脚跟自然略抬；换成反手握拍，手臂自然抬起，球放在拍前，再向前小幅平推。两种短发都要控制力量与拍面，不能照搬高远发球的大摆幅。

### 放网的最后一步与三步上网

讲师不是先教整场跑位，而是**先摆最后一步能击球的姿势，再把前面的步法接进来**。正手侧最后跨出持拍侧脚，脚掌方向打开、后脚跟自然略抬，手抬起如托住东西，拍头与手腕保持合适的平面关系。拍面微微立起，向前轻切或挡球头，动作柔和、触球后控制住。

三步上网的右手示范为：右脚先动 → 左脚后交叉跟进 → 右脚蹬跨出去。最后脚跟先落地，手上的动作与最后一步衔接；击球后用跟进、重心后移与垫步回动恢复，不停在网前。

反手放网沿用相同的三步组织，但必须先换成反手握拍。讲师纠正学员的重点仍是：右脚先跨，拍头与手腕关系稳定，向前轻挡而不是猛烈推送，回动时重心能撤回来。

| 学员练习中的纠正 | 纠正的是哪一环 |
| --- | --- |
| “柔一点、手放松” | 触球力度与握拍，不是要求整个动作慢吞吞 |
| “右脚先跨” | 上网步序，避免左脚先冲把后续步法打乱 |
| “最后一步脚跟先落地” | 到位与制动，不是只关注拍子有没有碰到球 |
| “手早一点伸” | 移动中就建立拍面准备，避免最后才抬手 |

### 勾球：准备像放网，最后平带切向斜线

正手勾球先将手与拍送出，准备与放网相似，到最后触球时拍头越过球的位置关系，再向左侧带切；反手勾球方向相反。共同点是**边带边切，拍头走平**。不是先把球停在拍上，再甩向另一侧，也不是用僵硬拍面直接把它弹过去。

讲师对学员逐项纠正：拍头应跟过去，拍面要转向目标；手腕向上撬会把球抬高，向下切得过多容易下网；只在原地用一下力、拍面不跟方向，球就不容易沿期望线路走。练习从原地手法开始，再加三步上网，保留同样的手法。

### 搓球：轻切球头，正反手方向对应

正手先把手自然托起，拍面与手掌方向对应，手腕向后展开，再用较小动作平着向前切球头；切到球后控制住，不继续大幅送拍。反手换握拍、拇指在下方托住，拍面略立起，从球的下方或后下方切球头底部，方向与正手相反。

反手示范还提醒拍头与手臂不能完全打直，应保留展开关系；手腕要有控制，不能变成整条胳膊在推。学员加步法时，讲师再次纠正不要左脚抢先走，要让手上的动作和最后一步配合。

放网、勾球、搓球虽然都在网前，触球任务不同：放网重在轻柔送过，勾球重在改变横向线路，搓球重在细小切击球头。先分清任务，再比较拍面，避免只记成“都轻一点”。

### 扑球：一步抢点与三步到位分别练

网前回球较高时，近距离可直接蹬出持拍侧脚迎球；距离较远，则用前面的三步上网。手上先让拍头抬起、拍面朝向前方，手腕展开，再向前并向侧方带出。原片让学员先练一步，再练三步，说明步法距离不同，触球的紧凑控制仍要保留。

反手扑球换成反手握拍，拇指向前顶、下面三指向后收，结合拍面向前的出球。讲师特别提醒若只向前直冲，拍子容易碰网，因此示范包含向侧方带出的方向；这个带出必须建立在合法触球与可控随挥上，不能把“带向边上”理解成任意越网挥拍。

### 挑球：拍头向前上方，不是向身侧甩

正手挑球与正手发球的最后发力有相似处，但上网挑球不是把拍子重新大幅拉到身后。手早伸出，最后用拍面变化与短促发力，把球向前上方顶出去。讲师纠正学员“不要往边上带”，强调食指根部的参与及手腕发力方向。

反手挑球先换握拍，展开拍头，手臂与肘回收组织，再打开拍面、用拇指和手指向前顶，并带出向上的拍面变化。跨步时把身体控制住，不能抬高重心向前冲。原片多次用“手上动作在脚落地之前做完”提示衔接，这个口令强调拍子要及时迎球，不能等冲到网前站死才挥拍。

### 推球：用相似准备隐藏向前点出的变化

正手推球开始时让拍头放下、拍面较平，看起来像准备搓球；在触球阶段用食指根部顶拍、手腕与转拍向前短促点出。讲师纠正的是“点出去”的集中发力，不是把整只拍子平移很远。它属于较主动的网前抢点处理。

反手推球同样先把拍面放平、拇指支撑，在最后用拇指向前顶、下面三指配合收转，让拍面立起并对正目标。学员被纠正“不是切球，要顶正、直接弹”：准备相似不等于触球也相同，搓球继续切，推球最后转正向前点。

### 头顶、反手与被动过渡

### 正反手接杀：同一到位，分出挡短与回后场

正手接杀的示范先用脚步转向来球，拍头同时向外打开，在前方轻挡，这是放网前的处理；若要回后场，再展开拍面，以食指根部与手腕的短促发力向前送出。两种球共用接杀准备，区别落在最后力量和拍面，不能每次都先拉一个很长的动作。

反手接杀同样先让脚掌、身体转向来球，持拍手在身体前方轻挡。回后场时，手臂回收、展开拍面，用拇指向前送出。讲师在学员练习中纠正：拍头不要乱动，先稳住拍面；回后场要有回收与向前加速；手法要跟脚步衔接，而不是最后站住再想打哪一种球。

### 正反手平抽：平着向前送出的发力链

正手平抽的手臂、肘先向后组织，在后方展开拍面，再由小臂、手指与转拍把拍头向前平扫。讲师让学员比较“直接向前推”与“先组织再平抽”的区别，强调拍面最后要转正。

反手平抽与反手挑球的发力有相似处，但出球方向不同：挑球从下向上送，平抽在较平的位置向前出。手臂回收时放松，随后拇指向前顶出；步法出去，手上的动作同步完成。准备时就攥紧拍柄、手臂没有组织空间，容易只剩硬顶。

### 后退交叉步与垫步：重心不是始终压在一条腿上

交叉步从中央准备位置开始，右脚先启动，重心移到右腿并向后组织，手上的准备同时向后展开；左脚从右脚后方交叉过去，第三步再让右腿承接到位。原片纠正腿不要绷直，要保持自然弯曲与弹性。

垫步则把两腿之间的重心转换突出出来：先由右腿启动，左脚向右脚方向靠近，重心移到左腿，右腿继续向后。它不是双脚贴着地面一起拖走。练习时看每一步由哪条腿承接、哪条腿继续蹬出，手上的举拍准备要随这个过程建立。

### 直线吊、对角线吊、反手吊：最后一段怎样改变

正手直线吊在前两阶段沿用高远准备，拍面先转正，接近触球时向左下方滑切，边向前边切球，再放松收拍。对角线吊同样不提前改掉准备，最后通过拍面向内转动与切击方向改变线路。讲师纠正大臂不要先落得太快，要保留最后手腕、拍面的处理空间。

反手吊从反手高远的收拍、提肘进入，区别是不以高远球的强力正面发力直接打出去，而在触球附近轻切、略带下压。换握、转身和提肘仍要有，不能为了“轻”就省略整套准备。

### 反手高远、反手到位与被动过渡的区别

### 两种后场跳起的分解对照

普通后场跳起示范：准备时重心移到右腿、腿自然弯曲 → 右腿向上蹬起 → 空中完成转身与挥拍 → 左脚承接落地。讲师建议先把左脚略抬起、练持拍侧腿的蹬跳，再加转身，最后连成完整动作，说明练习先后是蹬跳、转身、挥拍配合。

“中国跳”突击示范：先右脚转向后场、重心移到右腿，手臂同时展开 → 向后方直接蹬起 → 在空中处理来球 → 落地保持与起跳方向相应的姿势，重心由后腿承接。讲师提醒空中身体要控制住，不要动作变形。它与前一个转身跳起的区别，主要在方向和转体组织，不能只按名字判断。

## P07 · 基本步法：到位、制动、回动

### 四种基本步，按距离组合

| 步法 | 原片演示特点 | 用途 |
| --- | --- | --- |
| 并步 | 一脚先移动，另一脚跟上，保持双脚间空间 | 侧向移动、后退及连续调整 |
| 交叉步 | 两脚交替跨过，覆盖距离较大 | 较远距离移动、杀球后上网 |
| 垫步 | 在原有步法中补一小步 | 最后距离不足、网前抢点 |
| 蹬跨步 | 后脚蹬地，持拍侧脚向目标跨出 | 最后到位、网前击球及接杀 |

### 正反手上网：最后一步要能停住

准备时双膝自然弯曲、脚跟略抬，保持可启动的状态。正手侧可用并步、交叉步、垫步或蹬跨步组合；反手侧的持拍侧脚需要转向目标。**前几步完成移动，最后一步完成到位与制动**，不要到最后才伸手够球。

原片反复示范最后跨步时脚跟先接触地面、随后过渡到脚掌，保持身体稳定；重点看落地后还能否控制重心和回动。角度数字只是该示范中的讲解，不应当成每个人必须照量的姿势。

### 接杀步法：重心低，动作小

来球近，可转动支撑脚、一步跨出；来球较远，先用快速小步调整，再跨出接球。正反手都要让视线与身体朝向来球，拍子放在身体前方。原片另有反手侧直接伸左脚的应急示范，用来处理很快的来球，不是每次接杀的固定步法。

### 后场步法：转身、举拍与退步同时开始

正手后退先启动、侧身，手脚同步组织；原片用并步示范到位，在击球与落地后把重心带回前方。另示范了快速侧向抢攻和双打后场横向移动，不能把所有后退都做成同一个转体幅度。

反手后场先转动持拍侧脚，身体转向后方，拍子从腹前组织、提肘挥出。头顶区域基本动作与正手相通，但退步方向不同；回动可以并步，也可以按距离用交叉步。避免身体已经转过去，脚却拖在后面。

### 四种基本步法怎样接起来

并步开始时双脚分开，膝自然弯曲，脚跟略抬。一脚先走、另一脚跟上，但不要在移动中把两脚完全并拢，原片用保留一点距离帮助保持重心。交叉步则让另一脚从前方或后方交叉，覆盖的距离不同；方向改变时仍要保持身体准备。

垫步是距离差一点时的补充：原来步法已经接近目标，再补小步使最后跨步有条件到位。原片既示范够不到时的补步，也示范主动抢网前点；它不等于所有来球都先多跳一次。蹬跨步则由后侧脚蹬出、持拍侧脚跨向球，前面的并步或交叉步把它送到合适距离。

### 正手上网：准备、移动、最后一步分开观察

准备时略半蹲，不站死，脚跟略抬使前脚掌能启动。并步上网从右脚先出、左脚跟上进入；交叉步上网是右、左、右，第二脚跟进时衔接最后蹬跨，原片把它与杀球后上网联系起来。

距离判断稍有不足，可以补垫步，再抢最后接触点；蹬跨步则明确后脚跟到前脚后侧、再蹬出。四种组合不是四套互斥的规定动作，而是让自己在不同距离上仍能完成同一个可控的最后到位。

最后跨步脚跟先接触地面，再过渡到脚掌。讲师在示范中用膝下方大于直角、约 100 度的口令解释“不要向前弓得太过、停不住”；这个数字保留作识别原片的线索，复习时看整体跨步、身体和回动，不把它当作所有体型与速度下的固定测量标准。

### 反手上网：换方向，不是换掉所有步法

原片先在中央建立右脚在前的准备，转向左前方来球，再分别演示并步、交叉、垫步与蹬跨。与正手的共同点是最后到位和制动；不同点是持拍侧脚转向的幅度较大，身体要朝向这边的来球。

不要站在中央只把手伸到反手侧，脚仍朝正手方向；也不要为了“转过去”让步子绕得很大。看持拍侧脚怎样转、后脚怎样跟、最后一跨是否仍能稳定接球，能分辨自己缺的是方向还是距离。

## P08 · 连贯步法：让这一拍为下一拍准备

[P08 连贯步法技巧 · 完整原片](../../../../vn-resources/bilibili/BV17t411j7Qr/p08/video.mp4#t=0,769) · [在 B 站观看 P08](https://www.bilibili.com/video/BV17t411j7Qr/?p=8)

**后场 → 前场**：挥拍后重心向前，用并步衔接交叉步上网。直线距离较短；斜线需要覆盖更大距离，中间步与最后跨步随之调整。原片强调前两步快速、贴近地面，最后一步拉开、稳住，避免每一步都抬得很高。

**前场 → 后场**：网前击球后保持能判断下一拍的准备。对方挑球，再转身退后，手与脚同时抬起组织后场动作。网前直线、网前斜线与头顶方向都要分别练，不要把“上去放网—退后击球”做成互不相连的两段。

连贯练习的检查点：击球后没有停住看球；下一次启动由来球决定；到位后仍能控制重心；拍子始终跟着准备动作走。

### 后场到前场：直线与斜线的步长分配

先从头顶后场的转身击球进入，挥完拍重心向前，接并步、交叉步上网。直线线路先演示这一完整连接，斜线则覆盖更长的横向距离，中间一步和最后跨步需要相应加大。不能复制直线的小步长，再靠最后伸手补全部距离。

正手后场的演示沿用同一概念：后退用并步组织，向前用交叉步衔接。讲师纠正跑动时脚不要离地过高，前面两步快、最后一跨拉大并适度制动，让触球时稳。最后一步“稍慢”是到位的控制，不代表前面也慢着走。

[P08 00:22–01:45 头顶后场直线上网](../../../../vn-resources/bilibili/BV17t411j7Qr/p08/video.mp4#t=22,105) [P08 01:48–03:00 斜线的中间步与最后一步](../../../../vn-resources/bilibili/BV17t411j7Qr/p08/video.mp4#t=108,180) [P08 03:15–06:15 正手前后连接与步长纠正](../../../../vn-resources/bilibili/BV17t411j7Qr/p08/video.mp4#t=195,375)

### 前场到后场：守网准备中保留转身条件

网前处理完，原片先做小幅回动，保持持拍侧脚在前的守网准备；看到对方挑球，再转身并步退后。这个停在可启动姿势的阶段很关键：不是放完网就不看球，也不是预先转背朝后、放弃对方仍可能回网前的球。

正手方向与斜线方向分别带球示范，斜线前场处理要先到位、跨步覆盖足够距离，再接后退。头顶方向另强调手脚同时向后：转身时手已经抬起，拍子与脚步一起建立后场准备。原片最后比较慢示范与快速示范，速度增加后仍保留同样的动作连接。

### 连贯步法的逐环自查

| 看哪一环 | 需要回答的问题 |
| --- | --- |
| 后场击球结束 | 身体是否已经有向前回动条件，还是重心仍向后掉 |
| 对方准备击球 | 是否恢复到能判断、能启动的位置 |
| 前两步 | 是否及时、紧凑，承担了主要移动距离 |
| 最后跨步 | 是否把人和拍子送到可控接触位置，而非只伸手够 |
| 网前打完 | 是否仍看着对方，保留再次上网或退后的可能 |
| 转后场时 | 脚步与举拍是否同时开始 |

这些问题是对原片连接过程的归纳。先把一条直线回合做完整，再比较斜线所需的距离调整，更容易定位是单项击球出了问题，还是击球之间的恢复出了问题。

## P09 · 发球：同一准备，改变落点与节奏

[P09 发球战术 · 完整原片](../../../../vn-resources/bilibili/BV17t411j7Qr/p09/video.mp4#t=0,1043) · [在 B 站观看 P09](https://www.bilibili.com/video/BV17t411j7Qr/?p=9)

### 正手发高远、平快与网前球

正手准备左脚前、右脚后，持球与持拍动作协调，球拍自然后摆，放球后向前上方击球。**高远球**追求后场深度与较高弧线；**平快球**在共同准备中加快触球阶段的向前动作，压缩接球时间；**网前球**缩小手臂和身体摆动、控制拍面与力量，让球以较低轨迹过网。

[P09 正手发球准备](../../../../vn-resources/bilibili/BV17t411j7Qr/p09/video.mp4#t=40,70) [P09 00:20–04:05 正手高远发球](../../../../vn-resources/bilibili/BV17t411j7Qr/p09/video.mp4#t=20,245) [P09 04:15–07:00 平快发球](../../../../vn-resources/bilibili/BV17t411j7Qr/p09/video.mp4#t=255,420) [P09 07:10–10:00 正手网前发球](../../../../vn-resources/bilibili/BV17t411j7Qr/p09/video.mp4#t=430,600)

网前球过高，先检查拍面是否过分朝上、动作是否太大，而不是只提醒自己“轻一点”。平快球要检查线路与落点是否真能逼对方调整；被对方舒服地截击，就失去了变化的目的。

### 反手短发与后场变化

拇指支撑拍柄宽面，掌心留空间，持拍手在身体前方。短发用紧凑动作控制刚过网的弧线；发后场球保留相近准备，在触球阶段加快、集中发力。不要先做一个很明显的大动作，让对方提前判断要偷后场。

[P09 反手发球近景](../../../../vn-resources/bilibili/BV17t411j7Qr/p09/video.mp4#t=630,660) [P09 10:10–13:30 反手握拍及后场变化](../../../../vn-resources/bilibili/BV17t411j7Qr/p09/video.mp4#t=610,810) [P09 13:40–15:20 反手网前发球](../../../../vn-resources/bilibili/BV17t411j7Qr/p09/video.mp4#t=820,920)

### 发球抢攻：提前想好第三拍

观察接发人的习惯线路与站位，用网前、后场和线路变化迫使对方回球质量下降，再衔接第三拍。发球不是孤立地“发进去”，而是让自己的下一拍有准备。短发质量差、让对方直接扑压，第三拍的设想就无法实现。

[P09 15:40–17:24 发球与抢攻线路](../../../../vn-resources/bilibili/BV17t411j7Qr/p09/video.mp4#t=940,1043)

**规则校正**：原片“过腰、过手”和“停顿发球”的讲解有年代背景。按 BWF 标准发球条款，触球时整个球低于 1.15 米；发球开始后拍子须连续向前，双方就绪后不得不当拖延。不要把原片停顿示范理解成发球动作中途可以停住。[BWF 发球条款 9.1](https://system.bwfbadminton.com/documents/folder_1_81/Statutes/CHAPTER-4---RULES-OF-THE-GAME/SECTION%204.1-%20Laws%20of%20Badminton.pdf)

### 正手高远发球：站位、放球、转动与落点

原片站位示范靠近中线，距离前发球线约一米五，左脚前、右脚后。这个距离描述的是该示范，不是站位的唯一选择；靠中线也不能踩线。持球手准备，球拍自然后摆，放球后从右下方向左上方挥出，肩部转动与小臂、手腕发力衔接。

讲师分两次看脚和手：先看放球、挥拍的先后，再看身体转动时脚部怎样配合。发高远的任务是让球有高度并到后场深处，不能只飞得高，却落在中场给对手舒服进攻。发球开始后的脚部接触与移动须符合规则，片中的转脚示范应结合本 P 的规则校正理解。

[P09 00:22–01:48 正手站位与放球挥拍](../../../../vn-resources/bilibili/BV17t411j7Qr/p09/video.mp4#t=22,108) [P09 02:04–04:04 高度、深度及脚部示范](../../../../vn-resources/bilibili/BV17t411j7Qr/p09/video.mp4#t=124,244)

### 平快发球：共同准备，触球时向前加速

讲师将高远发球的“向上”与平快发球的“向前”对照：站位、持球和准备尽量相近，触球一瞬间用较快的小臂、手腕动作向前发力。不是先明显改成一个完全不同的大动作，否则变化会被看出来。

右发球区的示范特别指向接发人的中线附近，让对方以不舒服的位置处理球，再为前三拍争取主动。看落点时要同时看对方站位，不能只记住“发中线就有效”。先不带球练向前的拍面和角度，再带球确认线路，是原片的练习顺序。

[P09 04:16–05:25 向上与向前发力对照](../../../../vn-resources/bilibili/BV17t411j7Qr/p09/video.mp4#t=256,325) [P09 05:30–06:55 中线落点与练习顺序](../../../../vn-resources/bilibili/BV17t411j7Qr/p09/video.mp4#t=330,415)

### 正手短发：收小动作，调整拍面

大臂和身体不再像高远发球那样大幅摆动，动作收小，在身体前侧方用小幅向前平推。触球附近有控制与回收的感觉，不把手臂继续向前长推，把球送得过远。短发的低弧线同时依赖力量和拍面，不是握紧拍子后尽力“少用一点力”。

| 现象 | 原片排查与纠正 |
| --- | --- |
| 总发得太高 | 看拍面是否过分朝上，将出球方向调向前方 |
| 球走得远 | 看大臂与身体摆动是否仍像发高远，触球附近是否缺少控制 |
| 动作僵硬、方向不稳 | 放松并协调挥拍，保留小幅送出，而非拍子突然硬碰球 |
| 每次调整都不同 | 先固定准备，再观察同一个拍面变化对弧线的影响 |

### 反手发球：握拍空间、线路与短长变化

拇指支撑拍柄宽面，掌心留活动空间，持拍手不要缩在身体里，留出向前推出的控制范围。片中区分向中线附近与向外侧附近的线路变化，指的是在有效发球区域里的目标选择，不能误解为把球发到非对角区域。

短发时动作紧凑、力量轻，拍面不要过分上仰，否则球过网后偏高、容易被扑。讲师还说明不同身高下可作小幅拍面调整，所以“拍面平”应结合出球结果理解，不能只复制一张截图的绝对角度。

反手发后场平快球保留相近准备，触球时小臂、手腕发力更集中，拇指配合向前顶。球拍后收后连贯推出，**不能后收停住再重新发力**；讲师指出这样会让发力脱节。肩部准备放松，不用明显耸肩、大幅拉手提示对方。

### 发球抢攻：观察习惯，准备第三拍

原片先谈对手习惯：第一拍喜欢直线还是斜线，在什么站位下常回哪一种球。随后选择短发、后场或平快变化，争取让对方在准备不足时挡出较高网前球，或回出中场半高球，再衔接扑、杀。

把过程拆成：观察接发准备 → 选择有针对性的发球 → 看回球质量 → 第三拍处理 → 恢复后续准备。不能省略第三步，把预想线路当成已经发生；对方若回得好，就须先应对真实来球，而不是照原来的抢攻计划硬打。

## P10 · 接发球：准备一致，处理随来球改变

[P10 接发球战术 · 完整原片](../../../../vn-resources/bilibili/BV17t411j7Qr/p10/video.mp4#t=0,399) · [在 B 站观看 P10](https://www.bilibili.com/video/BV17t411j7Qr/?p=10)

右手示范左脚前、右脚后，后脚跟略抬，重心能迅速启动，手与拍子在前上方准备。**接高远球**转身、退到球后方再击球；**接平高和平快球**降低准备重心、缩小肩和大臂摆幅，以紧凑的小臂与手腕动作迎击。是否能下压由到位与击球条件决定，不是每个平快球都强行杀。

[P10 接发准备](../../../../vn-resources/bilibili/BV17t411j7Qr/p10/video.mp4#t=20,50) [P10 00:10–02:15 接高远球](../../../../vn-resources/bilibili/BV17t411j7Qr/p10/video.mp4#t=10,135) [P10 02:30–04:15 接平快球](../../../../vn-resources/bilibili/BV17t411j7Qr/p10/video.mp4#t=150,255)

**接网前发球**及时向前，拍子尽量保持在能主动处理球的位置，根据来球选择扑、推、搓、勾。准备时就放低拍子，容易被迫从下方起球。判断应结合发球人的握拍、准备与常用线路；启动必须等合法时机，不能提前冲进球场。

[P10 接网前发球](../../../../vn-resources/bilibili/BV17t411j7Qr/p10/video.mp4#t=290,320) [P10 04:25–06:39 网前接发](../../../../vn-resources/bilibili/BV17t411j7Qr/p10/video.mp4#t=265,399)

### 共同准备为何采用左脚前、右脚后

右手示范双手与拍子在前上方，身体重心能向前启动，后脚跟略抬。讲师解释采用左脚在前，是为了接后场发球时可以较快转身、举拍与后退；若同一示范姿势中右脚在前，还要多一次调整才进入后场动作。

这套准备既要保留向前接短发，也要保留后退接长发。手先抬起，看到高远发球后双手向后组织、身体转动，再并步退到球后方，接上高远等后场击球。对方发球之前就把身体全部转去后场，也会放弃前场来球的处理条件。

[P10 00:10–01:40 共同准备与后退转身理由](../../../../vn-resources/bilibili/BV17t411j7Qr/p10/video.mp4#t=10,100)

### 接平高、平快发球的两类主要错误

第一类是准备重心过高，启动和转向较慢；第二类是来球后肩部、大臂挥得太大，拍子还在准备，球已经越过合适处理位置。原片的纠正是小臂、手腕发力为主，动作简洁、出手快。

讲师演示一步后退下压，以及来球更靠后时的转身下压。它们共同要求先判断距离、及时建立击球位置；不是所有平快发球都用同一个退步幅度，更不是在身后也一律强杀。复习时分别看启动、拍子准备和接触点，能分清自己是脚慢还是手臂动作太长。

[P10 02:30–03:32 重心偏高与大摆幅的错误](../../../../vn-resources/bilibili/BV17t411j7Qr/p10/video.mp4#t=150,212) [P10 03:32–04:15 带球接平快示范](../../../../vn-resources/bilibili/BV17t411j7Qr/p10/video.mp4#t=212,255)

### 接网前发球：主动拍位与观察线索

从共同准备进入，持拍侧脚及时蹬向前，拍头尽量处于能从较高位置主动处理球的状态。原片比较拍子在手上方与落到手下方的区别：前者有扑、推、搓、勾的选择，后者更容易被迫从下面起球。

观察发球人的站位、准备、手型与常用线路，是判断线索，不是能够直接知道对方想法。后脚跟略抬有助于及时启动，但仍要等合法时机才能移动。把“准备抢”与“提前抢”分开：前者是手和重心已就绪，后者是发球尚未完成就先移动。

[P10 04:26–05:18 较高拍位与主动处理](../../../../vn-resources/bilibili/BV17t411j7Qr/p10/video.mp4#t=266,318) [P10 05:18–06:38 站位手型观察与后脚启动](../../../../vn-resources/bilibili/BV17t411j7Qr/p10/video.mp4#t=318,398)

## P11 · 单打战术：先明确要调动什么

[P11 单打战术 · 完整原片](../../../../vn-resources/bilibili/BV17t411j7Qr/p11/video.mp4#t=0,633) · [在 B 站观看 P11](https://www.bilibili.com/video/BV17t411j7Qr/?p=11)

| 原片打法 | 怎样形成被动 | 自己需要具备什么 |
| --- | --- | --- |
| 控制后场、高球压制 | 连续或左右调动后场，对方上网后再推回后场 | 体能、后场深度、网前处理质量 |
| 打四角球 | 用准确前后左右落点，让对方持续移动 | 落点准确、手感稳定，自己能跟上节奏 |
| 下压为主、控制网前 | 杀吊逼出挡网或不到位挑球，再上网控制 | 杀吊落点、上网速度、网前质量 |
| 快拉快吊、前后结合 | 平高与较快吊球变化，趁对方重心未恢复继续推压 | 出手紧凑、变化及时、网前抢推 |

**高球压制**不是单纯“多打高远”，而是让球有后场深度，用连续性消耗对方、等待短回球。**四角调动**也不是随意打四个方向；每一拍落点必须足够好，否则对方提前到位，自己反而被动。

[P11 后场压制示范](../../../../vn-resources/bilibili/BV17t411j7Qr/p11/video.mp4#t=50,80) [P11 00:20–02:00 控制后场](../../../../vn-resources/bilibili/BV17t411j7Qr/p11/video.mp4#t=20,120) [P11 02:10–04:30 四角调动](../../../../vn-resources/bilibili/BV17t411j7Qr/p11/video.mp4#t=130,270)

**杀吊上网**要求后场出球已经让对手不舒服，再衔接网前。杀到边线、控制挡网、抓住不充分挑球，是原片的串联示范。**快拉快吊**通过小动作快速改变前后落点，争取在对方尚未恢复重心时继续处理下一拍；快建立在质量与连贯上。

[P11 杀吊后的上网](../../../../vn-resources/bilibili/BV17t411j7Qr/p11/video.mp4#t=360,390) [P11 04:45–07:40 下压与控网](../../../../vn-resources/bilibili/BV17t411j7Qr/p11/video.mp4#t=285,460) [P11 07:55–10:33 快拉快吊](../../../../vn-resources/bilibili/BV17t411j7Qr/p11/video.mp4#t=475,633)

### 控制后场、高球压制：用连续性消耗

原片针对打完后场便快速回动的对手，继续把球送回后场，或在两侧后场调动，让对方反复退回去。对方上网后，再以有质量的网前处理和快速送后场连接，把前后移动也加进去。得分来自移动中的被动与失误，不是所有高球本身都会直接赢球。

采用这种打法，自己也要能持续移动、有后场深度并能处理网前。讲师把体能作为主要前提；若自己连续球的质量先下降，就可能先给对方进攻。复习应看两条后场线路是否真把人拉开、网前回球是否让对方不能舒服压球，而非统计打了多少高远球。

[P11 00:42–01:58 后场连续压制的对象与前提](../../../../vn-resources/bilibili/BV17t411j7Qr/p11/video.mp4#t=42,118)

### 四角球、高低结合：落点准确才能调动

四角不是机械按左前、右后、右前、左后循环。原片强调每一处落点准确，针对移动较慢的对手，把前后左右拉开，再在对方跑动露出问题时抓进攻。自己的手感与技术控制是前提，否则调动球不到位，只会让对方早早站好反击。

可按这一链观察原片：一拍把对方送离中央 → 下一拍落在他较难及时到位的位置 → 看回球是否偏短或过高 → 再加速。每拍仍须由实际回球决定，不事先规定对方一定会回哪一侧。

[P11 02:14–03:08 四角落点与适用对象](../../../../vn-resources/bilibili/BV17t411j7Qr/p11/video.mp4#t=134,188) [P11 03:08–04:30 四角带球调动](../../../../vn-resources/bilibili/BV17t411j7Qr/p11/video.mp4#t=188,270)

### 下压控网：杀吊之后还有第二层任务

先用杀球或吊球压对方两侧较靠边的落点，让对方回球被动；随后上网搓或平推，迫使对方挑球不够到后场；自己再在较靠前的位置接下一次下压机会。链条是 **边线下压 → 上网控制 → 逼出不到位球 → 再下压**。

讲师多次提醒网前质量的重要性。如果网前处理偏高，对方可以直接主动推压，就不会按设想挑球；如果后场下压太舒服，对方挡网也容易，自己上网便未必有利。杀球落点、上网速度与网前手感，缺任何一项都不能只靠“多杀”补回来。

[P11 04:46–05:34 杀吊、搓推与不到位挑球](../../../../vn-resources/bilibili/BV17t411j7Qr/p11/video.mp4#t=286,334) [P11 05:34–07:40 边线下压后衔接网前](../../../../vn-resources/bilibili/BV17t411j7Qr/p11/video.mp4#t=334,460)

### 快拉快吊：抓对方还没恢复的时间

后场平高与较快、较轻的吊球连接，动作小、出手快；吊出网前后及时上去抢推，争取在对方未回中央、重心未调整好时把下一球推出。快不只体现在球的飞行，还体现在自己的处理与下一拍连接。

对照示范时看三个时间点：自己的球什么时候离拍、对方什么时候完成上一拍回动、自己什么时候上去处理下一拍。若对方已经恢复，而自己仍用一个没有落点质量的快速推球，快的优势就消失了。

## P12 · 双打发接发：第一拍就分工

[P12 双打战术 · 完整原片](../../../../vn-resources/bilibili/BV17t411j7Qr/p12/video.mp4#t=0,412) · [在 B 站观看 P12](https://www.bilibili.com/video/BV17t411j7Qr/?p=12)

这一 P 的核心是发接发站位。原片混双示范前后分工：前方控制网前，后方随时补位；前方队员适度降低身体位置，避免遮挡后方视线。把它理解为该示范组合的职责分配，不能按性别直接推定谁一定更强、谁只能守网。

[P12 混双发球站位](../../../../vn-resources/bilibili/BV17t411j7Qr/p12/video.mp4#t=80,110) [P12 00:25–03:25 混双发接发](../../../../vn-resources/bilibili/BV17t411j7Qr/p12/video.mp4#t=25,205)

男双、女双示范也是前方发球、后方准备，距离要让后方看得清并能及时接上。原片给出距离估计，复习重点是**能覆盖、能启动、互不阻挡**，而非固定站在某个测量点。

接发者手与拍子向前准备，重心较低，等对方发球后及时上前，用小臂与手腕的小动作抢处理。要同时保留应对后场发球的转身退步；一味前扑会被偷后场。前几拍应让双方都知道谁守网、谁覆盖后场。

[P12 双打接发准备](../../../../vn-resources/bilibili/BV17t411j7Qr/p12/video.mp4#t=300,330) [P12 03:30–06:52 男双女双及后场接发](../../../../vn-resources/bilibili/BV17t411j7Qr/p12/video.mp4#t=210,412)

### 混双两种发球场景的具体位置

原片第一种场景由前方队员发球，后方队员双脚分开、半蹲，保持注意力，站得不能离前方过远。讲师以距后场线约一米的示范位置说明后方还要能补位，不能退到很深的位置，只准备接后场球。

第二种场景由后方队员发球，搭档站在前场中央，身体稍降低，保留后方视线与网前准备。两种场景的共同目标是发球以后能立即接上分工；站位不是把发球者安置好就结束，搭档也必须有覆盖和准备。

这些是片中的混双组合示范。实际前后职责应按队员能力、发球选择与回球形势调整，不能把片中某个性别的位置固定成所有组合的规定。

[P12 00:36–01:28 前方发球、后方补位](../../../../vn-resources/bilibili/BV17t411j7Qr/p12/video.mp4#t=36,88) [P12 01:30–02:05 后方发球与避免遮挡](../../../../vn-resources/bilibili/BV17t411j7Qr/p12/video.mp4#t=90,125)

### 男双、女双：后方准备须能兼顾两种回球

前方发球者靠前，后方示范距离发球者约一米半，离双打后发球线约一米，站在较中央位置、双脚分开、半蹲，持拍侧脚略前。讲师既说这样便于启动接上手球，也说发球质量不好时要准备接杀，说明后方不是只等一个理想的第三拍。

距离数字用于复现示范位置，不是要求两人永远保持精确间距。检查的是：是否能看见对手、能启动到两侧、发球被抢时能否防守、短回球出现时能否补到位。

### 接发的手脚：低重心与较高拍位同时成立

左脚前、右脚后，后脚跟略抬，身体重心稍低，但手与拍子向前伸起。原片同时提醒这两点，说明“低重心”不等于把手也放到腿旁边。接网前时用小臂、手腕的小动作，少用肩部大摆幅，争取在较高位置主动处理。

出脚与接球要及时衔接，不能提前移动。准备越充分，越不需要提前冲出去：拍子已经在位置、脚能立即启动，看到真实发球再选择短球或后场处理。

### 应对后场发球：不能只准备网前扑球

原片从接短发的准备转到后场来球，先用后侧腿组织半蹲、后退与转体，手同时进入后场举拍。另示范较平快来球的快速向后跳动处理。观察它与高远来球的距离差别，不能每次都先做网前跨步，再被动回头追球。

接发时主动拍位、准备重心和后腿启动共同服务于两种来球：短发出现时向前处理，长发出现时向后到位。若为了抢短发而失去后退条件，对方的后场变化就容易奏效。

## P13 · 双打站位：跟着球的攻守状态转换

[P13 双打站位 · 完整原片](../../../../vn-resources/bilibili/BV17t411j7Qr/p13/video.mp4#t=0,614) · [在 B 站观看 P13](https://www.bilibili.com/video/BV17t411j7Qr/?p=13)

### 防守：左右展开，联防中路

本方挑起高球后，原片由前后站位转换为左右并排防守。双膝自然弯曲，重心降低，拍子放在身体前方，挥拍紧凑。不要因为刚才自己在网前，就仍站在前面等对方杀球。

当球主要压到伙伴一侧，另一人不只是守自己半场，还要**联防两人中间的结合部**。中路的责任随来球和位置改变；两人都只盯边线，中间就会出现空当。

[P13 并排防守站位](../../../../vn-resources/bilibili/BV17t411j7Qr/p13/video.mp4#t=70,100) [P13 00:20–03:00 防守准备](../../../../vn-resources/bilibili/BV17t411j7Qr/p13/video.mp4#t=20,180) [P13 03:10–04:40 中路联防](../../../../vn-resources/bilibili/BV17t411j7Qr/p13/video.mp4#t=190,280)

### 进攻：前封后攻，击球后补回来

后方杀吊下压、前方封网，形成前后站位。后方用快速横向移动覆盖后场，击球后及时恢复；前方看对方挡网，主动在较高位置接球。两人不能都跟着同一落点移动，把另一侧全部让出来。

### 补位：填伙伴暂时覆盖不了的地方

进攻时，伙伴上前扑球，另一人根据对方回球准备补另一端网前或后场；防守时，伙伴被迫挑球并向一侧退，另一人展开到另一侧，同时照顾中路。伙伴被拉出边线，要主动靠近中央补空当，不要等他自己跑回来。

### 防守准备的手、脚、握拍分别检查

本方起高球后，从前后迅速退成左右防守。原片右脚略前、左脚后，双膝自然弯曲，身体稍前倾；脚跟只略抬，不做明显踮高。拍子拿在身体前方，不能缩得太近，否则挥拍组织受限。

防守挥拍强调小臂、手腕的小动作，不用大臂大幅摆动。讲师示范反手握拍时拇指顶宽面，说明这种握法在对应防守球上出手较快；实际仍需按正反手来球调整，不能因此把所有防守拍面锁死成反手。

### 联防中路：两个人不只是各管半场

来球压到一侧时，直接受压的一人准备处理该球，另一人帮助守两人中间的结合部。原片解释另一侧往往有更长的来球距离和调整时间，可以利用这个时间联防。若双方各自只盯自己的边线，中路来球可能落在两人都来不及照顾的位置。

联防应随着对方击球方向与伙伴位置移动，不是另一人每次都站到中央等球。复习看三个位置：对方击球处、伙伴受压处、自己的可覆盖区域；再看中路是否仍留着明显空当。

### 进攻站位：后方恢复，前方保持较高处理点

后方负责杀吊等下压，尽量维持本方进攻条件；用横向并步到位，击球后迅速收回重心。讲师强调不要让前方封网者因为后方没有恢复，反复向后追球。

前方看到对方挡网，及时跨出、把拍子举起，在较主动位置封网。两人虽是前后站位，仍要根据出球方向覆盖空当；前方不是固定站在网中央，后方也不是打完一拍就等在那里。

### 进攻补位有两个去处：另一端网前或后场

伙伴向一侧扑球，只能覆盖这一侧；另一人根据对方回球，补另一端网前，或者准备对方挑到后场的球。原片把这两种情况分别演示，并提醒根据对方动作与局势判断是补前还是补后。

不要看到伙伴上网，自己也跟到同一处。要先问：他目前覆盖了哪里、下一球可能到哪里、自己该填哪块空当。补位的目的不是靠得越近越好，而是保持两人能连续接上。

伙伴被迫从网前挑球，可能沿直线退，也可能斜退到另一侧。另一人不能预设他一定回某个固定位置，应根据实际退步填到另一侧，组成并排防守。原片正手、反手区域各演示一次，再加中路与前场覆盖。

如果伙伴挑直线，补防者还要照顾中路，同时留意对方吊前场；伙伴刚从网前退下，可能来不及再次上网，补防者要保持能帮到前方的条件。最后示范伙伴被拉出场地边缘时，另一人迅速补中央，等他回动后再恢复双方覆盖。

讲师用两人不要拉得过远、示范约一米半的距离作提醒。重点是不能一人在场地一端、另一人在另一端，把中央与相邻区域全部放空，不是整个回合都用同一间距测量两人位置。

## P14 · 双打战术类型：攻击目标要明确

[P14 双打战术类型 · 完整原片](../../../../vn-resources/bilibili/BV17t411j7Qr/p14/video.mp4#t=0,494) · [在 B 站观看 P14](https://www.bilibili.com/video/BV17t411j7Qr/?p=14)

| 战术 | 目标 | 下一拍怎样接 |
| --- | --- | --- |
| 攻人、追身 | 压迫较难处理的一方，缩小对方挥拍空间 | 观察被动回球，前后配合继续压制 |
| 杀中路 | 打两人结合部，让判断与分工承受压力 | 抓住犹豫、抢球或质量差的回球 |
| 攻后场 | 左右调动后场队员，消耗移动与回动 | 等回球质量下降再加速下压 |
| 前封后攻 | 后场持续下压，网前快速拦截 | 后场打完恢复，前场保持封网准备 |

**攻人**的判断依据是实际回球与移动能力。原片在混双示范中选定一名队员持续追身，这是示例，不应把性别当作识别弱点的方法。**杀中路**攻击的是双方的分工缝隙；自己的防守则要明确中路责任，呼应 P13 的联防。

[P14 追身与中路位置](../../../../vn-resources/bilibili/BV17t411j7Qr/p14/video.mp4#t=160,190) [P14 00:10–02:20 攻人示范](../../../../vn-resources/bilibili/BV17t411j7Qr/p14/video.mp4#t=10,140) [P14 02:30–04:30 杀中路](../../../../vn-resources/bilibili/BV17t411j7Qr/p14/video.mp4#t=150,270)

**攻后场**要靠左右拉开让后方队员反复移动，等待出球质量下降；不是无条件把每个球都挑高。**前封后攻**需要两边同时有能力：后方能连续下压并恢复，前方能快速封网；后方只顾一次强杀、前方没有衔接，不能形成连续进攻。

[P14 前封后攻配合](../../../../vn-resources/bilibili/BV17t411j7Qr/p14/video.mp4#t=430,460) [P14 04:40–06:20 攻后场](../../../../vn-resources/bilibili/BV17t411j7Qr/p14/video.mp4#t=280,380) [P14 06:30–08:14 前封后攻](../../../../vn-resources/bilibili/BV17t411j7Qr/p14/video.mp4#t=390,494)

### 攻人：观察谁难处理，再持续压迫

先通过几次回合观察两名对手的防守与移动，选实际处理较差的一方。原片用追身球示范，目标在持拍侧身体、肩部至躯干一带，让对方没有舒服展开挥拍的空间。前方封网与后方下压都配合这个目标，而不是后方攻一边、前方随意换另一边。

追身不是只把球打向人，就自动有质量：还要看高度、速度和接触时机是否真让对方受压。对方若已及时调整、能舒服处理，应看真实回球再衔接，而非因为预先选定目标，就无视其他空当。

[P14 00:22–01:15 选定对象与追身区域](../../../../vn-resources/bilibili/BV17t411j7Qr/p14/video.mp4#t=22,75) [P14 01:16–02:18 前后配合追身示范](../../../../vn-resources/bilibili/BV17t411j7Qr/p14/video.mp4#t=76,138)

### 杀中路：攻击双方交接的判断问题

结合部就是两人防守区域中间的衔接处。原片演示两种问题：双方都不确定谁接，造成犹豫；或者两人同时抢一个球，回球质量下降。中路并非始终等于球场几何中心，它随两人实际位置变化。

后场杀向结合部、网前打到两人交接区域，都可以给判断增加压力；随后抓住质量差的回球继续进攻。反过来练防守时，P13 的联防要解决同一问题：伙伴受压，自己照顾中间，不让两人之间变成无人负责的地方。

[P14 02:36–03:22 结合部、犹豫与同时抢球](../../../../vn-resources/bilibili/BV17t411j7Qr/p14/video.mp4#t=156,202) [P14 03:22–04:28 中路进攻带球示范](../../../../vn-resources/bilibili/BV17t411j7Qr/p14/video.mp4#t=202,268)

### 攻后场：让后方连续横移，等质量下降

原片通过吊球、平挡和平抽等线路，把对方后场主要处理球的人左右拉开，让他持续移动、消耗体力，等待回球质量下降后再进攻。关键是后方队员有没有真正被调动，不是每拍都一律挑到后场。

要同时观察对方前场拦截者。如果自己的线路先被前方舒服截住，就没有把球送到预期对象。比较这项战术与单打的四角调动：这里针对的是双打前后分工中的后方连续覆盖压力，仍需两人配合处理回球。

[P14 04:42–05:10 攻后场的左右调动机制](../../../../vn-resources/bilibili/BV17t411j7Qr/p14/video.mp4#t=282,310) [P14 05:10–06:18 调动后的进攻机会](../../../../vn-resources/bilibili/BV17t411j7Qr/p14/video.mp4#t=310,378)

### 前封后攻：连续两拍以上才看得出分工

后方有较强的下压与快速恢复，前方出脚、出手快，能把对方挡网及时拦下来。讲师还强调后方连续杀下一拍的体力支撑：一次杀得很快，不等于后面能持续覆盖；前方一开始站在网前，也不等于已经封得住。

观察一个完整串联：后方下压 → 对方挡网 → 前方处理 → 对方再起球 → 后方已恢复并能继续进攻。任何一个环节断了，都要回头查相应技术，不能只把它归为“战术没有用”。

## P15 · 跳起技术：起跳前到位，落地后回动

[P15 跳起技术 · 完整原片](../../../../vn-resources/bilibili/BV17t411j7Qr/p15/video.mp4#t=0,404) · [在 B 站观看 P15](https://www.bilibili.com/video/BV17t411j7Qr/?p=15)

**双脚起跳杀球**的场景是网前质量好，迫使对方挑球，自己有时间退到球后方、向前起跳击球。原片强调先到位，再起跳；不是在球已越过身体时靠跳起来补救。后退快速，准备展开，挥拍与起跳协调，落地后继续为下一拍准备。

[P15 双脚起跳示范](../../../../vn-resources/bilibili/BV17t411j7Qr/p15/video.mp4#t=140,170) [P15 00:20–03:15 双脚起跳杀球](../../../../vn-resources/bilibili/BV17t411j7Qr/p15/video.mp4#t=20,195)

**半转体起跳**用较快的后场移动衔接挥拍，原片先拆脚步，再加持拍手，再带球。注意手不要一直留在身体后方；移动时就建立举拍准备。落地后的重心迅速向前回动，接上 P08 的前后连贯，避免打完一拍就留在后场。

[P15 半转体起跳与回动](../../../../vn-resources/bilibili/BV17t411j7Qr/p15/video.mp4#t=310,340) [P15 03:30–06:45 半转体起跳](../../../../vn-resources/bilibili/BV17t411j7Qr/p15/video.mp4#t=210,404)

这两种起跳动作都建立在稳定的地面击球、到位和恢复能力上。复习时先看自己是否退到球后方、落地是否可控、是否还能接下一拍，再比较跳高和球速。

### 双脚起跳杀球：机会从上一拍网前质量开始

片中不是从原地跳高开始，而是先放出有质量的网前球，对方被迫挑起，自己才有较充分的时间后退准备。退步要快，先到球后方，身体展开，再向前起跳挥拍。若上一拍放网偏高、对方直接推压，便不会提供同样的跳杀条件。

起跳前到位、空中展开与向前挥拍、落地后的回动，是一条链。讲师先不带球演示“放网—后退—起跳”，再带球，说明动作学习要保留来球场景，而非只单独模仿空中的姿势。原片提到腿部与腰腹能力作为前提，实际复习先确认自己是否能完成到位和恢复。

[P15 00:22–01:02 网前质量与退到球后方](../../../../vn-resources/bilibili/BV17t411j7Qr/p15/video.mp4#t=22,62) [P15 01:02–02:25 放网、后退与向前挥拍](../../../../vn-resources/bilibili/BV17t411j7Qr/p15/video.mp4#t=62,145) [P15 02:26–03:16 双脚起跳带球示范](../../../../vn-resources/bilibili/BV17t411j7Qr/p15/video.mp4#t=146,196)

### 半转体起跳：小步移动中手已开始准备

先演示双脚分开、小步并步移到位置，再起跳；随后加入手：持拍手放在胸前可组织的位置，后退时就举起来，而不是到后场才从腿旁抬拍。挥拍用小臂、手腕向前处理，身体转动方式与前一组完整转体的双脚跳杀不同。

讲师口令里同时出现“不要转体”和“半转体”，应结合这一组画面理解为不过度做前一组的大幅身体转换，而非在空中把身体完全锁住。比较的是移动与恢复方式，不能只抠单个口令后把两个动作当成互相矛盾。

[P15 03:46–04:32 半转体脚步分解](../../../../vn-resources/bilibili/BV17t411j7Qr/p15/video.mp4#t=226,272) [P15 04:32–05:18 举拍与小臂向前挥](../../../../vn-resources/bilibili/BV17t411j7Qr/p15/video.mp4#t=272,318)

### 落地以后，马上接下一拍

落地后重心迅速回动、步法向前，衔接 P08 的连续步法。讲师明确说明：如果打完留在后场，对方一挡网，自己就接不到。回动不是等看清球已到网前才开始，而是击球结束便恢复可应对的位置，再根据对方真实回球启动。

| 自查现象 | 对应缺项 |
| --- | --- |
| 球到身后才起跳 | 后退与判断不足，跳起无法补回失去的击球位置 |
| 退到位才慢慢举拍 | 手没有在移动中建立准备 |
| 跳得高，落地后站不稳 | 空中和落地的控制没有接起来 |
| 杀完能得一拍，下一球总赶不上 | 缺少落地回动与前后连贯 |
| 只会原地跳，不会从网前衔接 | 练习遗漏了上一拍和移动场景 |
