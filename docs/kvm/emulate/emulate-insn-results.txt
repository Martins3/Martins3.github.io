统计口径
CALL 是 x86_emulate_instruction() 入口；INSN 是 kvm_emulate_insn 解码记录。
NO_DECODE 是之前解码指令的 I/O 续接，不能算成新的解码。
INSN start 表示模拟尝试，不表示该指令已退休；REP 一条指令也可能多次进入。
MMIO/PIO 只记录该入口执行期间发生的事件，不是整个 VM 的全部 I/O。
MMIO unsatisfied-read 与完成后的 read 是不同阶段，不能简单相加作为独立设备访问次数。
续接的设备事件关联到同一 vCPU 最近的解码记录；续接没有新的硬件 VM exit。
设备名根据启动完成后的 QMP info mtree -f 匹配；启动时已改变的 BAR 地址不一定能匹配。

本次采样的具体发现
最常见字节 44 88 65 00：mov [rbp+0x0],r12b，出现 30699 次，guest RIP=0x7f6eb54d。
对应 GPA 位于 0xffc00000 起的 system.flash1（OVMF_VARS.fd）；这是实际的 flash MMIO 写。
该条指令不是 IN/OUT，也不是因为 CPU 不支持 MOV；它访问了 QEMU 模拟的 flash。
同时可见 virtio PCI 配置访问、xHCI 寄存器、IOAPIC 和 APIC 访问。
f3 6c：rep insb，关联 PIO 0x511（QEMU fw_cfg），体现字符串 I/O 的完整模拟。
入口标志没有 TRAP_UD、SKIP 或 invalid-guest-state 样本；不能推断其他工作负载也没有这些路径。
OVMF 首次启动的 flash 写占了很大比例，这份统计描述这台新 VM 的启动窗口。
