# cgroup V1

## 如何强制配置是 v1 还是 v2
添加启动参数:
systemd.unified_cgroup_hierarchy=0 systemd.legacy_systemd_cgroup_controller=1
```txt
[root@localhost 11:29:53 cgroup]$ ls
blkio  cpuacct      debug    freezer  misc     net_cls,net_prio  perf_event  rdma
cpu    cpu,cpuacct  devices  hugetlb  net_cls  net_prio          pids        systemd

[root@localhost 11:29:54 cgroup]$ uname -r
6.18.3-martins3-00001-gd99e6e036338-dirty
```

不过，在 fedora 43 上安装这个是没有效果的

## v1 和 v2 如何区分

```txt
# stat -fc %T /sys/fs/cgroup/
cgroup2fs
```

```txt
# stat -fc %T /sys/fs/cgroup/
tmpfs
```

## 需要打开如下结构才可以

```txt
CONFIG_MEMCG=y
CONFIG_MEMCG_V1=y
CONFIG_CPUSETS=y
CONFIG_CPUSETS_V1=y
CONFIG_PROC_PID_CPUSET=y
```

另外，Linux 内核本身尚未完全移除 cgroup v1；但 systemd 从 v256 开始默认拒绝v1，
并已在 v258 完全删除 v1 支持。
- systemd v256 https://github.com/systemd/systemd/releases/tag/v256
- systemd v258 https://github.com/systemd/systemd/releases/tag/v258
