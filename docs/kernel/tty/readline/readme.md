# GNU Readline 交互式 demo

Readline 是用户态库，通过终端接口处理按键和重绘输入行。
它不是 Shell 解释器；
此 demo 按空白分隔命令名和参数，不解析引号、变量、管道，
也不执行外部命令。`echo` 原样打印参数。
