# 我发现内核中存在日志
在当前这台 Fedora 主机上，你看到的 Message from syslogd@... 主要由 /etc/rsyslog.conf 中这条规则产生：

```txt
*.emerg    :omusrmsg:*
```

它把所有来源的 emergency 级别日志发送给当前登录用户的终端，所以 SSH、tmux 中也可能看到；这不等于日志被写入了
/dev/console。rsyslog 的 omusrmsg 文档
(https://docs.rsyslog.com/doc/configuration/modules/omusrmsg.html)说明了这个输出方式。

你记录的另一种提示 Broadcast message from systemd-journald@... 来自 journald：本机默认
ForwardToWall=yes、MaxLevelWall=emerg。因此同一条紧急日志可能被 journald 和 rsyslog 各广播一次。journald 配置文档
(https://www.freedesktop.org/software/systemd/man/252/journald.conf.html)区分了发给所有登录终端的 ForwardToWall
和写入系统控制台的 ForwardToConsole。

真正向 /dev/console 输出的 rsyslog 规则在本机配置中是注释状态：

#kern.*    /dev/console

另外，内核 printk 按 console= 和 console loglevel 直接输出，是独立于上述 syslog 广播的路径。
