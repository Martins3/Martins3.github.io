# Rust 学习记录

我在大三(2018)的时候尝试过学习
但是发现很难

然后我们当时得出来的结论就是，我之所以学不会，是因为我没有办没有反复使用，我没有使用 Rust 的项目。然后我就想那我就用 Rust 去写 new code，对吧？然后我发现了一个问题，new code 当时的第一道题目就是一个链表。这个电表我就完全写不来。然后我就知道这个确实有一个项目叫做 Too Many List 什么 Learn Rust 这样的一个项目。结果我发现这个项目读起来，非常非常非常的痛苦。然后然后就是遇到太多阻塞，这个事情又断掉了。

但是现在有了 AI 的帮助的话，事情变得完全不同了。我尝试直接去写一道题目，然后中间不是，就是先是流程是这样的，就是我先去用 AI 快速地过了一遍那个 learn Rust with too many list 这个项目，然后过了之后，当然肯定都很多东西是记不住啊，或者没有理解，但无所谓，我们赶快就开始做题。做题的时候，你就开始，哎，在这道题目里面，你仔细去思考，仔细去想，哎，为什么它要这么设计？写到哪一步它会编译报错？这样东拼西凑一步步来，最后做完了之后，你再回去去看这个项目。这个时候，像类似于 Rust 里面的 RC 啊、CLR 啊、Reference Cell 啊。这之类的概念，你基本上就全部清楚了。
