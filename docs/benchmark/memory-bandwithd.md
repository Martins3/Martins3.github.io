# 内存带宽

2400 MT/s 里的 MT/s 是 MegaTransfers per second(每秒百万次传输),和 MHz(时钟频率)不是一回事。这是理解它的关键。

1. MT/s vs MHz

┌──────┬──────────────────────────────────────┐
│ 概念 │ 含义                                 │
├──────┼──────────────────────────────────────┤
│ MHz  │ 时钟信号每秒震荡的次数(时钟频率)     │
├──────┼──────────────────────────────────────┤
│ MT/s │ 数据线每秒实际传输的次数(数据传输率) │
└──────┴──────────────────────────────────────┘

DDR(Double Data Rate)内存在时钟的上升沿和下降沿各传输一次数据,所以一个时钟周期传 2 次。

对 DDR4-2400 来说:
- 内存时钟频率 = 1200 MHz
- 数据传输率 = 1200 × 2 = 2400 MT/s

所以 2400 MT/s 完整读法是"每秒 24 亿次数据传输",对应的内存颗粒时钟其实是 1.2 GHz。

2. 带宽怎么算

每次传输一个通道的数据位宽是 64 bit = 8 字节,因此单通道带宽:

```
  2400 MT/s × 8 B = 19200 MB/s ≈ 19.2 GB/s
```

- 单通道 → 19.2 GB/s
- 双通道(主流消费级)→ 38.4 GB/s
- 四通道 → 76.8 GB/s

3. 常见对应关系

┌───────────┬──────────┬────────────┐
│ 内存标称  │ 时钟频率 │ 单通道带宽 │
├───────────┼──────────┼────────────┤
│ DDR3-1600 │ 800 MHz  │ 12.8 GB/s  │
├───────────┼──────────┼────────────┤
│ DDR4-2400 │ 1200 MHz │ 19.2 GB/s  │
├───────────┼──────────┼────────────┤
│ DDR4-3200 │ 1600 MHz │ 25.6 GB/s  │
├───────────┼──────────┼────────────┤
│ DDR5-4800 │ 2400 MHz │ 38.4 GB/s  │
├───────────┼──────────┼────────────┤
│ DDR5-6000 │ 3000 MHz │ 48 GB/s    │
└───────────┴──────────┴────────────┘

4. 一句话总结

2400 MT/s = 数据线每秒传输 24 亿次;因为 DDR 一个时钟周期传两次数据,所以真实内存时钟是 1200 MHz,单通道带宽约 19.2 GB/s。

注意厂商宣传里常把"2400 MHz"和"2400 MT/s"混用(标称频率直接叫 MHz),严格说 DDR4-2400 的时钟是 1200 MHz、传输率才是 2400 MT/s。
