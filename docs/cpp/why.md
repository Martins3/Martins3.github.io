# 为什么我在 2026 年依旧学习 c++

AI 让学习 c++ 的痛苦部分基本上下降为 0 ，剩下的部分都是
可以让人思考的部分，这些可以做实验的小游戏是很有意思的。

大量的项目还是 c++ 实现的，这是工作中需要的。

最近用 C 语言写了一个比较大的项目，
数据结构管理全部使用链表，体验非常之差。
在 2026 年，其实我认为任何项目使用的语言都应该收敛到 Rust 和 Python。
