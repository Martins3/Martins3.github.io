Tensor Core 相比已经做过 shared-memory 和寄存器分块的 CUDA Core，仍快约 2.88x。

正确性结果：

- 优化 CUDA Core 与基线完全一致。
- WMMA 最大绝对误差：0.000686646
- WMMA 最大相对误差：约 6.8e-6
- 超出容差的元素：0
- CPU 抽样校验：PASS

反汇编也确认了执行路径：

- CUDA Core kernel 使用 FFMA 指令。
- Tensor Core kernel 使用 HMMA.16816.F32 指令。

Tensor Core 和 CUDA Core 的区别可以概括为：

 CUDA Core                   Tensor Core
━━━━━━━━━━━━━━━━━━━━━━━━━━  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 通用浮点/整数计算单元       专用矩阵乘加单元
──────────────────────────  ──────────────────────────────────────────
 每个线程执行普通算术指令    一个 Warp 协作执行矩阵 tile
──────────────────────────  ──────────────────────────────────────────
 GEMM 被拆成大量 FFMA        一条 HMMA 完成一组矩阵乘加
──────────────────────────  ──────────────────────────────────────────
 运算和控制流比较灵活        对数据类型、形状、布局和对齐有限制
──────────────────────────  ──────────────────────────────────────────
 适合一般 CUDA kernel        适合 GEMM、神经网络和张量计算
──────────────────────────  ──────────────────────────────────────────
 通常支持 FP32 等通用精度    常使用 FP16/BF16/TF32 输入并以 FP32 累加

最核心的区别不是“Tensor Core 的时钟更快”，而是执行粒度不同：
CUDA Core 一次处理普通线程级算术；Tensor Core 一次处理整个矩阵小块，因此矩阵乘法吞吐量高得多。

这份教学实现仍不是硬件峰值实现。cuBLAS/CUTLASS 会使用更复杂的流水线、异步拷贝、双缓冲和架构专用指令，性能通常还会明显更高。代码已通过 clang-format、编
译和运行验证，未执行 git stage 或 commit。
