1. TVM (Apache TVM)
定位: 端到端机器学习编译器框架
做什么:
• 接收 PyTorch/TensorFlow/ONNX 等高框架的模型，经过图优化、算子优化、代码生成，编译成可在各种硬件（CPU、GPU、NPU、FPGA、手机芯片）
  运行的高效代码
• 提供多层中间表示（Relax 做图级，TensorIR 做算子级），以及自动调优框架（AutoTVM / Ansor / MetaSchedule）
核心价值: 跨硬件性能可移植性——同一个模型，无需手写 CUDA，就能在多平台上接近手写内核的性能。
───────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
2. Triton (OpenAI)
定位: GPU 编程语言和编译器
做什么:
• 让开发者用 Python 风格的语法直接编写 GPU 内核（如矩阵乘法、FlashAttention、LayerNorm），无需手写 CUDA C++
• 编译器自动处理线程块划分、共享内存管理、同步等底层细节
• 主要面向 NVIDIA GPU（也逐步支持 AMD），是 PyTorch 2.0 torch.compile 的底层代码生成工具之一
核心价值: 大幅降低 GPU 内核开发门槛，同时保持接近 cuBLAS/cuDNN 的性能。
───────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
3. TileLang
定位: 基于 TVM 的高性能算子 DSL
做什么:
• 与 Triton 目标完全一致：用 Python DSL 写高性能 GPU/CPU/加速器内核
• 但 TileLang 直接构建在 TVM 之上，底层复用 TVM 的 TensorIR、代码生成和自动调优能力
• 支持更多后端：NVIDIA CUDA、AMD HIP、Apple Metal、华为 Ascend NPU、WebGPU 等
核心价值: 类似 Triton 的开发体验 + TVM 的跨平台编译能力。
